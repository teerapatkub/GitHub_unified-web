## สิทธิ์ admin มาจากไหน

สิทธิ์ตัดสินจาก `users.role = 'admin'` ในฐานข้อมูลทุกครั้งที่มีคำขอ (ADR 0003, D08) ไม่ใช้ token รุ่นเก่า
เปลี่ยน role แล้วมีผลกับคำขอถัดไปทันที ไม่ต้อง login ใหม่

## ยกหรือถอนสิทธิ์

ทำเฉพาะแถวที่ต้องการ และให้เจ้าของโปรเจคยืนยันก่อนทุกครั้ง

```sql
UPDATE users SET role = 'admin' WHERE user_id = <id>;  -- ยกสิทธิ์
UPDATE users SET role = 'user'  WHERE user_id = <id>;  -- ถอนสิทธิ์
```

## ถ้ารหัสผ่านหลุด

1. เปลี่ยนรหัสผ่านที่หน้า "ลืมรหัสผ่าน" หรือใน Supabase Dashboard → Authentication → Users
2. ถ้าสงสัยว่ามีคนใช้บัญชีแล้ว ให้ถอนสิทธิ์ admin ก่อน แล้วตรวจสิ่งที่ถูกแก้ในหน้า admin
