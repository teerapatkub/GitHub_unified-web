# Sitemap — โหมด Arcade Battle Royale

ฟังก์ชันหลักของโหมด Arcade ทั้งหมด แยกตามช่วงการพัฒนา

| ช่วง | หมายความว่า |
|---|---|
| **1. ทำเสร็จแล้ว** | ผู้เล่นใช้งานได้จริงตอนนี้ |
| **2. กำลังพัฒนา** | ตกลงขอบเขตแล้ว อยู่ในคิวงานปัจจุบัน ยังใช้ไม่ได้ |
| **3. ยังไม่ทำ** | รู้ว่าขาด แต่ยังไม่ได้เริ่มและยังไม่กำหนดว่าจะทำเมื่อไร |

**ทางเข้า:** หน้าหลัก → `โหมดเกม` → `/matchmaking` (ต้องล็อกอินก่อน)
**ที่อยู่ของโค้ด:** `client/src/pages/Arcade/` · `server/server.js` · `shared/arcadeConfig.json`
