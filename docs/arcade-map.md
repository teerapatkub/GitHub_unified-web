# 3. ยังไม่ทำ

| # | งาน | ทำไมถึงสำคัญ |
|---|---|---|
| 1 | **เปลี่ยนจาก polling เป็น WebSocket** | ตอนนี้ข้อมูลช้ากว่าความจริงได้ถึง 2 วินาที และยิง request ตลอดเวลา |
| 2 | **หน้าอธิบายกติกาสำหรับคนเล่นครั้งแรก** | คนใหม่ยังไม่รู้ว่ารอบไหนคัดกี่คน หรือเงินสดกับเหรียญต่างกันอย่างไร |
| 3 | **ห้องความยาก `default` สุ่มโจทย์จากคลัง** | ตอนนี้รอบ 1-3 ยังใช้โจทย์ตายตัว 3 ข้อ เล่นซ้ำแล้วเจอโจทย์เดิม |
| 4 | **กู้คืนโค้ดเมื่อเน็ตหลุดกลางรอบ** | ฉบับร่างถูกเก็บไว้ที่เซิร์ฟเวอร์แล้ว แต่หน้าจอยังไม่เอากลับมาใส่ใน editor ให้ |
| 5 | **หน้าสรุปแยกให้เห็นว่าเสียคะแนนไปกับอะไร** | เห็นแต่คะแนนรวม ไม่รู้ว่าตกที่เทสเคส คุณภาพโค้ด หรือเวลา |
| 6 | **ทดสอบบนมือถือและทดสอบหลายห้องพร้อมกัน** | เขียนเผื่อไว้แล้วทั้งคู่ แต่ยังไม่เคยลองจริง |
