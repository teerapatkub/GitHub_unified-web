# แผนผังโหมด Arcade Battle Royale

แผนที่ของโหมด Arcade ทั้งโหมด — ผู้เล่นเดินจากหน้าไหนไปหน้าไหน แต่ละหน้าเรียก API อะไร
ข้อมูลไปนอนอยู่ตารางไหน และกติกาที่ตัดสินผลอยู่ตรงจุดใด

ใช้คู่กับ [`CONTEXT.md`](../CONTEXT.md) (อภิธานศัพท์) และ
[`docs/adr/0001-server-owns-the-verdict.md`](adr/0001-server-owns-the-verdict.md)
(ทำไมการตัดสินอยู่ฝั่ง server)
เฉลยโจทย์ทุกข้ออยู่ที่ [`docs/arcade-solutions.md`](arcade-solutions.md)

**อัปเดตล่าสุด:** 2026-08-25

## 1. ทางเข้า

| ทาง | เงื่อนไข |
|---|---|
| `/matchmaking` | ต้องล็อกอินแล้ว ถ้ายังไม่ล็อกอินจะถูกส่งไป `/login` |

ทั้งโหมดอยู่ในคอมโพเนนต์เดียวคือ `client/src/pages/Arcade/ArcadeBattleRoyale.jsx`
หน้าจอย่อยทุกหน้าเป็น *view* ที่สลับกันตาม **เฟสของห้อง** ไม่ใช่ route แยก
— กด back ระหว่างแมตช์จึงไม่ได้เปลี่ยนหน้า แต่จะเด้งกล่องยืนยันการออกกลางคัน

## 3. ลำดับเฟสของแมตช์

**server เป็นคนเดินเฟส** ไม่ใช่เบราว์เซอร์ — `tickArcadeMatches()` วนทุก 1 วินาที
มองหาห้องที่ `phase_deadline` เลยเวลาแล้ว จบเฟสนั้นให้ทีละก้าว
เบราว์เซอร์แค่ poll มาดูว่าตอนนี้เฟสอะไรและเหลือเวลาเท่าไร

```
LOBBY
  └─ หัวห้องกดเริ่ม (ต้องมีผู้เล่น ≥ 2 คน) และสุ่มโจทย์ของทั้งแมตช์ตรงนี้ครั้งเดียว
       ↓
ROUND_1 ──→ SUMMARY_1 ──→ SHOP_1 ──┐
                                    ↓
ROUND_2 ──→ SUMMARY_2 ──→ SHOP_2 ──┤   คัดออก 2 คน หลังรอบ 2
                                    ↓
ROUND_3 ──→ SUMMARY_3 ──→ SHOP_3 ──┤   คัดออก 1 คน หลังรอบ 3
                                    ↓
ROUND_4 ─────────────────────────→ RESULT   คัดออก 1 คน หลังรอบ 4
```

| เฟส | มาตรฐาน | โหมดเร็ว |
|---|---|---|
| ROUND_1..4 | 60 วินาที | 30 วินาที |
| SUMMARY_1..3 | 5 วินาที | 5 วินาที |
| SHOP_1..3 | 20 วินาที | 15 วินาที |

**รอบ 1 ไม่คัดใครออก** เป็นรอบวัดฝีมือล้วน และ**ห้ามใช้ไอเทม**
ห้องเล็กที่เหลือผู้รอดชีวิตคนเดียวก่อนรอบ 4 จะจบแมตช์ตรงนั้นเลย ไม่ลากต่อ

ค่าทั้งหมดอยู่ที่ `shared/arcadeConfig.json` ซึ่งทั้ง server, client และบอทอ่านไฟล์เดียวกัน
**ห้ามคัดลอกค่าพวกนี้ไปไว้ที่อื่น**

## 5. API

| Endpoint | ใช้ตอนไหน |
|---|---|
| `GET /api/arcade/rooms` | หน้ารายการห้อง (poll ทุก 3 วินาที) |
| `POST /api/arcade/rooms/create` | สร้างห้อง (รหัสผ่านถูก hash ก่อนเก็บ) |
| `POST /api/arcade/rooms/join` | เข้าห้องด้วยรหัส `ARC-xxxx` |
| `GET /api/arcade/rooms/:id` | **หัวใจของโหมด** — poll ทุก 2 วินาที ได้เฟส · เวลาหมดอายุเฟส · ผู้เล่นทุกคน |
| `POST /api/arcade/rooms/:id/settings` | หัวห้องแก้ตั้งค่า |
| `POST /api/arcade/rooms/:id/transfer-host` · `/kick` | จัดการห้อง |
| `POST /api/arcade/rooms/:id/add-bot` | เพิ่มบอท |
| `POST /api/arcade/rooms/:id/start` | เริ่มแมตช์ + สุ่มโจทย์ทั้งแมตช์ |
| `POST /api/arcade/rooms/:id/submit-round` | ส่ง**โค้ด** ไม่ใช่คะแนน — server เก็บไว้ตรวจตอนปิดรอบ |
| `POST /api/arcade/rooms/:id/shop-cash-delta` | หัก/คืนเงินตอนซื้อขาย |
| `POST /api/arcade/rooms/:id/attack` | ยิงไอเทมใส่ผู้เล่นอื่น |
| `GET /api/arcade/rooms/:id/effects` | poll ทุก 2 วินาที ดูว่าโดนอะไรอยู่ |
| `POST /api/arcade/rooms/:id/chat` · `GET .../chat` | แชท |
| `GET /api/arcade/rooms/:id/round-history` | โค้ดของตัวเองรายรอบ |
| `POST /api/arcade/rooms/:id/leave` · `/finish-choice` | ออกจากห้อง · เลือกอยู่ต่อหลังจบแมตช์ |
| `GET /api/arcade/players/:name/stats` · `/history` | สถิติอาชีพ · แมตช์ย้อนหลัง |
| `GET /api/arcade/tasks` · `/items` | คลังโจทย์ · แคตตาล็อกไอเทม |

**ไม่มี WebSocket** ทั้งโหมดเป็น REST polling ล้วน

## 6. ตารางในฐานข้อมูล

| ตาราง | เก็บอะไร |
|---|---|
| `arcade_rooms` | ห้องหนึ่งห้อง: รหัส · หัวห้อง · สถานะ · **`phase` · `phase_deadline`** · โจทย์ที่สุ่มไว้ · สรุปรอบล่าสุด |
| `arcade_participants` | ผู้เล่นหนึ่งคนในห้องหนึ่ง: คะแนน · เงินสด · ตกรอบหรือยัง · โค้ดที่ส่ง · เหรียญที่ได้ |
| `arcade_effects` | ไอเทมที่ถูกยิงแล้วยังไม่ถูกรับไปแสดงผล |
| `arcade_chat_messages` | ข้อความในห้อง |
| `arcade_round_history` | โค้ดที่แต่ละคนส่งในแต่ละรอบ **อยู่ต่อได้แม้ห้องถูกลบ** (เก็บ 10 แมตช์ล่าสุดต่อคน) |
| `arcade_player_stats` | สถิติอาชีพสะสมข้ามแมตช์ |
| `arcade_items` | แคตตาล็อกไอเทมสองภาษา |
| `problems` + `problem_modes` | **คลังโจทย์จริง** — `arcade_tasks` เป็น **view** ทับสองตารางนี้ เขียนผ่าน view ไม่ได้ |

ห้องจะถูกลบทันทีที่ไม่มีใครอยู่ ประวัติรอบจึงต้องไม่ผูก foreign key แบบ cascade กับห้อง

## 7. กติกา

### คะแนนรายรอบ — คิดที่ server ตอนปิดรอบ

```
คะแนน = (สัดส่วนเทสที่ผ่าน × 100)          ← รันโค้ดจริงด้วย problemGrader
       + คุณภาพโค้ด (0-100)                 ← AI ตัวตรวจโค้ด (คีย์แยกจากแชทบอท)
       + (สัดส่วนเทสที่ผ่าน × สัดส่วนเวลาที่เหลือ × 100)
       × 2 ถ้าใช้ Score Booster อยู่
```

ขาเวลาคูณด้วยสัดส่วนเทสที่ผ่าน**โดยตั้งใจ** — ถ้าจ่ายขาเวลาแบบเรียบๆ
การกดส่งโค้ดตั้งต้นทันทีที่รอบเปิดจะได้คะแนนฟรี

**เบราว์เซอร์ไม่มีสิทธิ์ตัดสิน** `submit-round` รับแต่โค้ด คะแนนที่ client ส่งมาถูกทิ้ง

### ส่งอัตโนมัติ

เตือนที่ 16 วินาที แล้วส่งให้เองที่ 8 วินาทีก่อนหมดเวลา
ต้องไม่เป็น 0 เพราะการตรวจใช้เวลาจริง และ server ปฏิเสธคำตอบที่มาถึงหลังปิดรอบไปแล้ว

### การคัดออก

คัดจาก**คะแนนสะสม** ไม่ใช่คะแนนของรอบนั้น · รอบ 2 คัด 2 คน · รอบ 3 คัด 1 คน · รอบ 4 คัด 1 คน
และจะไม่คัดจนเหลือ 0 คน

### เงินสดในแมตช์ กับ เหรียญจริง

| | เงินสด (Survival Cash) | เหรียญ (Code Coins) |
|---|---|---|
| ได้จาก | อันดับของแต่ละรอบ: 500 / 400 / 300 / 200 / 100 | อันดับสุดท้ายของแมตช์: 50 / 35 / 25 / 15 / 10 |
| ใช้ทำอะไร | ซื้อไอเทมในแมตช์นั้น | กระเป๋าเดียวกับบทเรียน ใช้ซื้อของในร้านค้าหลัก |
| อยู่ที่ | `arcade_participants.cash` — หายเมื่อจบแมตช์ | `users.virtual_currency` |

เริ่มแมตช์ด้วยเงินสด 0 — ทุกบาทมาจากการทำอันดับ
ชื่อที่ไม่ผูกกับบัญชีจริง (แขก/บอท) ไม่ได้เหรียญ

### ไอเทม 15 ชิ้น

| ประเภท | ชิ้น | ทำอะไร |
|---|---|---|
| โจมตี | Ink Fog · Backspace Lock · Key Scrambler · Screen Shake · Typo Generator · Cash Steal · Caps Lock Lock · Mirror Mode · Screen Dimmer | เลือกเป้าได้ 1 คน |
| วงกว้าง (aoe) | Time Freeze · Blackout | โดนทุกคนที่เหลือ ถือได้ครั้งละ 1 ชิ้น |
| เสริมตัวเอง | AI Helper · Shield · Tax Collection · Score Multiplier | — |

ถือได้พร้อมกัน 3 ชิ้น · ใช้ได้ตั้งแต่รอบ 2 เป็นต้นไป · Shield กันได้ 1 ครั้งแล้วหมดไป

## 8. บอท

บอทเป็น**คู่ซ้อม** ไม่ใช่ผู้เล่นจริง — ทุกอย่างที่บอททำในฝั่งเบราว์เซอร์เป็นภาพลวงตาล้วน
ส่วนคะแนน เงิน และการตกรอบของบอท **server สังเคราะห์ขึ้นเอง** ตามความยากของห้อง

| | |
|---|---|
| หลอด progress | เดินหน้าอย่างเดียว หยุดที่ 100% ต่อรอบ (บอทเร็วสุดจบราว 26-41 วินาที ช้าสุดมักไม่ทัน) |
| ซื้อของ | ตามบุคลิก — สาย SABOTEUR ซื้อไอเทมโจมตี 80% ของโอกาส |
| ยิงไอเทม | สาย REVENGE ยิงเฉพาะคนที่เคยยิงมันมาก่อน |
| ความเก่ง | ห้อง easy บอทอ่อนกว่าห้อง hard จริง (`botSkillByDifficulty`) |

## 10. ชุดทดสอบ

```bash
npm run test:arcade        # ใน server/ — รันทั้งชุดด้านล่าง
```

| ชุด | ตรวจอะไร | ต้องมี server รันอยู่ไหม |
|---|---|---|
| `test:tasks` | โจทย์ทั้ง 40 ข้อ เฉลยต้องผ่านเทสของตัวเอง | ไม่ |
| `test:score` | สูตรคะแนนที่ server คิด และโกงคะแนนจาก client ไม่ได้ | ต้องมี |
| `test:draw` | การสุ่มโจทย์ไม่ซ้ำและอยู่ในงบเวลาพิมพ์ของผู้เริ่มต้น | ต้องมี |
| `test:bot-progress` | หลอดบอทเดินหน้าอย่างเดียวและหยุดที่ 100% | ไม่ |
| `test:bots` | ห้อง easy ต้องเจอบอทที่อ่อนกว่าห้อง hard จริง | ต้องมี |

## 11. ที่ยังไม่มี

- **ยังไม่มีโหมดผู้ชมหลังกดส่ง** — กดส่งแล้วยังแก้โค้ดต่อได้ และดูโค้ดคนอื่นไม่ได้
- **ไม่มีการซิงก์โค้ดระหว่างเขียน** — server เห็นโค้ดของผู้เล่นครั้งแรกตอนกดส่งเท่านั้น
- **คอมเมนต์ `# TODO:` ใน starter_code ยังเป็นภาษาไทยทุกข้อ** แม้สลับหน้าเว็บเป็นอังกฤษ
- **โจทย์ประจำรอบ 1-3 ของห้อง `default`** ยังเป็นโจทย์ตายตัว 3 ข้อ ไม่ได้สุ่มจากคลัง
  (ห้อง easy/medium/hard สุ่มจากคลังจริงแล้ว)
