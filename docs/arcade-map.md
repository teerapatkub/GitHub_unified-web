# Sitemap — โหมด Arcade Battle Royale

ผังหน้าจอทั้งหมดของโหมด Arcade แบ่งตามสถานะการพัฒนา 3 กลุ่ม

| กลุ่ม | หมายความว่า |
|---|---|
| **1. ทำเสร็จแล้ว** | ผู้เล่นใช้งานได้จริงตอนนี้ และระบุไว้ว่าตรวจสอบด้วยวิธีใด |
| **2. กำลังพัฒนา** | ตกลงขอบเขตแล้ว อยู่ในคิวงานปัจจุบัน ยังใช้ไม่ได้ |
| **3. ยังไม่ทำ** | รู้ว่าขาด แต่ยังไม่ได้เริ่มและยังไม่ได้กำหนดว่าจะทำเมื่อไร |

**ทางเข้า:** หน้าหลัก → `โหมดเกม` → `/matchmaking` (ต้องล็อกอินก่อน ไม่งั้นถูกส่งไป `/login`)

ทั้งโหมดอยู่ที่ `client/src/pages/Arcade/` หน้าจอย่อยทุกหน้าสลับกันตาม**เฟสของห้อง**
ไม่ใช่ route แยก — กด back ระหว่างแมตช์จึงเด้งกล่องยืนยันแทนที่จะเปลี่ยนหน้า

[`docs/arcade-solutions.md`](arcade-solutions.md) (เฉลยโจทย์ทุกข้อ)

## ระบบเบื้องหลังที่เสร็จแล้ว

| ระบบ | สาระสำคัญ |
|---|---|
| **server เดินเฟสเอง** | `tickArcadeMatches()` วนทุก 1 วินาที เบราว์เซอร์แค่ poll มาดูว่าเฟสอะไร เหลือเวลาเท่าไร |
| **server ตัดสินคำตอบ** | `submit-round` รับแต่**โค้ด** คะแนนที่ client ส่งมาถูกทิ้ง · ตรวจด้วย `problemGrader.js` ที่รัน Python จริง |
| **สูตรคะแนน** | `(สัดส่วนเทสที่ผ่าน × 100) + คุณภาพโค้ดจาก AI (0-100) + (สัดส่วนเทสที่ผ่าน × สัดส่วนเวลาที่เหลือ × 100)` คูณ 2 ถ้าใช้ Score Booster |
| **การคัดออก** | คิดจากคะแนน**สะสม** · รอบ 1 ไม่คัดใคร · รอบ 2 คัด 2 · รอบ 3 คัด 1 · รอบ 4 คัด 1 · ไม่คัดจนเหลือ 0 คน |
| **เงินสองสกุลแยกกัน** | *เงินสด* จากอันดับรายรอบ (500/400/300/200/100) ใช้ในแมตช์นั้นแล้วหายไป · *เหรียญ* จากอันดับสุดท้าย (50/35/25/15/10) เข้ากระเป๋าเดียวกับบทเรียน |
| **สุ่มโจทย์ตามงบเวลาพิมพ์** | คัดเฉพาะโจทย์ที่ผู้เริ่มต้นพิมพ์ทันจริงในเวลาที่มี (90 ตัวอักษร/นาที) |
| **บอท 5 ตัว 4 บุคลิก** | ห้อง easy เจอบอทที่อ่อนกว่าห้อง hard จริง · คะแนนและการตกรอบของบอท server เป็นคนสังเคราะห์ |
| **เวลาเป็น UTC ทั้งอ่านและเขียน** | ผ่าน `db.js` ทางเดียว |
| **รหัสผ่านห้อง hash ด้วย bcrypt** | ไม่เก็บเป็น plain text |
| **ประวัติรอบอยู่ต่อแม้ห้องถูกลบ** | เก็บ 10 แมตช์ล่าสุดต่อคน |

# 2. กำลังพัฒนา

## 2.1 โหมดผู้ชมหลังกดส่งคำตอบ

ตอนนี้กดส่งแล้ว**ไม่มีอะไรเกิดขึ้นบนหน้าจอ** ยังพิมพ์แก้โค้ดต่อได้เหมือนเดิม
สิ่งที่ตกลงไว้ว่าจะเป็น:

```
กดส่งคำตอบ
├── ล็อกไม่ให้แก้โค้ดต่อ                          ← ยังไม่มี
├── เปลี่ยนเป็นโหมดผู้ชม                           ← ยังไม่มี
├── คลิกที่รายชื่อผู้เล่น เพื่อดูว่าคนนั้นเขียนถึงไหนแล้ว   ← ยังไม่มี
└── ยังใช้ไอเทมได้ตามปกติ                         ← ต้องปลดล็อกปุ่มที่ตอนนี้ถูกปิดหลังกดส่ง
```

**สิ่งที่ต้องสร้างเพิ่ม:** ตอนนี้ server เห็นโค้ดของผู้เล่น**ครั้งแรกตอนกดส่งเท่านั้น**
การจะดูว่าคนอื่นเขียนถึงไหนได้ ต้องมีการซิงก์โค้ดระหว่างที่ยังเขียนอยู่ —
คอลัมน์เก็บฉบับร่าง endpoint สำหรับส่งฉบับร่างเป็นระยะ และ endpoint สำหรับดึงโค้ดของคนอื่น
โดยเปิดให้ดูได้เฉพาะคนที่ส่งคำตอบไปแล้วหรือตกรอบไปแล้ว (คนที่ยังเขียนอยู่ต้องดูไม่ได้)

# 3. ยังไม่ทำ

## 3.1 เนื้อหาและโจทย์

- **ห้องความยาก `default` ยังใช้โจทย์ตายตัว 3 ข้อในรอบ 1-3** ไม่ได้สุ่มจากคลัง 40 ข้อ
  (ห้อง easy / medium / hard สุ่มจากคลังจริงแล้ว)
- **คอมเมนต์ `# TODO:` ใน starter_code ยังเป็นภาษาไทยทุกข้อ** แม้สลับหน้าเว็บเป็นอังกฤษ
  ต้องแยกเก็บเป็น `starter_code_en` ถึงจะแก้ได้
- **ยังไม่มีโจทย์จากโหมดแข่งที่หมดอายุไหลเข้ามาในคลัง Arcade** — ตกลงกันไว้ว่าโจทย์หมดอายุ
  จะถูกเก็บไว้แล้วนำไปสุ่มในโหมดอื่น แต่ยังไม่ได้เลือกว่าโหมดปลายทางคือบทเรียนหรือ Arcade

## 3.2 การเล่นหลายคน

- **ไม่มี WebSocket** ทั้งโหมดเป็น REST polling ล้วน (สถานะห้อง 2 วินาที · ไอเทม 2 วินาที ·
  แชท 2 วินาที · รายการห้อง 3 วินาที) เล่นได้ แต่ทุกอย่างช้ากว่าความจริงได้ถึง 2 วินาที
- **ไม่มีระบบชวนเพื่อนเข้าห้องโดยตรง** ต้องส่งรหัส `ARC-xxxx` ให้กันเอง
- **ไม่มีการจัดอันดับข้ามแมตช์แบบฤดูกาล** มีแค่สถิติอาชีพสะสม

## 3.3 หน้าจอ

- **ยังไม่ได้ทดสอบบนมือถือ** เลย์เอาต์เขียนไว้ให้ซ้อนกันบนจอแคบแล้ว แต่ไม่เคยลองจริง
- **ยังไม่มีหน้าอธิบายกติกาสำหรับคนเล่นครั้งแรก** มีแต่คู่มือไอเทม คนที่เพิ่งเข้ามาไม่รู้ว่า
  รอบไหนคัดกี่คน หรือเงินสดกับเหรียญต่างกันอย่างไร
- **หน้าสรุปผลไม่บอกว่าเสียคะแนนไปกับอะไร** เห็นแต่คะแนนรวม ไม่เห็นว่าตกที่เทสเคส
  คุณภาพโค้ด หรือเวลา

## 3.4 ความทนทาน

- **ผู้เล่นที่เน็ตหลุดกลางรอบยังไม่มีทางกู้คืนคำตอบ** เข้าห้องเดิมได้ แต่โค้ดที่พิมพ์ค้างไว้หาย
  (จะหายไปเองเมื่อทำข้อ 2.1 เพราะมีการซิงก์ฉบับร่างแล้ว)
- **ยังไม่มีการทดสอบว่าเล่นพร้อมกันหลายห้องแล้วยังไหว** ชุดทดสอบสร้างห้องทีละไม่กี่ห้องเท่านั้น
