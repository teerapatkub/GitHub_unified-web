# ข้อสอบก่อนเรียน / หลังเรียนด้วย AI

ใช้ **โมเดลในเครื่อง** (Ollama, ตัวเดียวกับแชทบอท Lumi) สร้างก่อนเรียน 5 ข้อ และหลังเรียน 5 ข้อ แต่ละชุดมีปรนัย 3 ข้อ และข้อเขียนตอบสั้น 2 ข้อ โดยอ้างอิงชื่อ คำอธิบาย และข้อความสไลด์ของบทเรียนที่เลือกจากฐานข้อมูล ไม่ต้องเขียนโจทย์เอง และไม่ต้องฝึกโมเดลหรือใช้ vector database

> **2026-10-28:** เดิมเรียก Gemini ด้วย API key แล้วเปลี่ยนเป็นโมเดลในเครื่องตอนรวมเข้า main เพราะอาจารย์กำหนดว่าห้ามใช้ API key ของ AI ภายนอก (Spec 0004) เนื้อหาบทเรียนจึงไม่ออกนอกเครื่อง

## ตั้งค่า

ไม่ต้องมีคีย์ ใช้ค่าเดียวกับแชทบอทใน env ของ server:

```dotenv
LLM_BASE_URL=http://localhost:11434/v1
LLM_CHAT_MODEL=scb10x/typhoon2.5-qwen3-4b
LLM_GENERATE_TIMEOUT_MS=240000
```

- โมเดลขนาด 4B บนการ์ดจอ 4 GB เขียนได้ราว 13 token/วินาที ข้อสอบ 10 ข้อจึงใช้เวลาราว 1–3 นาที
- `LLM_GENERATE_TIMEOUT_MS` จึงยาวกว่า `LLM_TIMEOUT_MS` ของแชท
- ถ้าเว้น `LLM_BASE_URL` หรือ `LLM_CHAT_MODEL` ว่าง ปุ่มสร้างจะตอบว่ายังไม่ได้ตั้งค่า (503) ส่วนอื่นของระบบใช้ได้ตามปกติ
- โมเดลเล็กผิดได้บ่อยกว่า cloud: ถ้าข้อสอบที่ได้ไม่ครบรูปแบบ ระบบจะปฏิเสธ (422) ให้กดสร้างใหม่ และต้องอ่านทุกข้อใน preview ก่อนบันทึก

## การใช้งาน

บันทึกข้อมูลบทเรียนและข้อความสไลด์ให้ครบก่อน เลือกบทที่ยังไม่มีข้อสอบ กด **สร้างด้วย AI (5 + 5 ข้อ)** ตรวจทั้งสองชุดและเฉลย แล้วกด **บันทึกข้อสอบทั้ง 10 ข้อ** หากไม่เหมาะสมกดสร้างชุดใหม่ได้ ร่างคงอยู่เมื่อ refresh ในแท็บเดิม มีอายุ 1 ชั่วโมง และต้องสร้างใหม่เมื่อ backend restart

AI ยังไม่อ่านข้อความจากภาพ/GIF/วิดีโอ ต้องใส่เนื้อหาหรือคำอธิบายเป็นข้อความด้วย ชื่อบทอย่างเดียวไม่เพียงพอ บทเรียนเกิน 60,000 ตัวอักษรต้องแบ่งเป็นบทเรียนย่อย ระบบตรวจรูปแบบ จำนวนข้อ และคำถามซ้ำ แต่ความถูกต้องทางวิชาการต้องตรวจใน preview

## ฐานข้อมูลและผลการเรียน

ใช้ตารางที่มีอยู่แล้ว ไม่ต้องรัน migration:

- `lessons` / `lesson_slides`: แหล่งเนื้อหาบทเรียน
- `lesson_quizzes`: ผูก `lesson_id` กับ `quiz_type` (`pre` หรือ `post`)
- `quiz_questions`: คำถามและเฉลย ชุดละ 5 ข้อ
- `question_choices`: ตัวเลือกข้อละ 4 ตัวเลือก
- `lesson_quiz_attempts`: ผลผู้เรียนตามระบบเดิม

ทั้งสองชุดบันทึกใน transaction เดียว มีการล็อกบทเรียนเพื่อป้องกันบันทึกซ้ำจากหลายแท็บ และตรวจว่าเนื้อหายังตรงกับตอนสร้าง AI ผู้เรียนได้รับข้อสอบผ่าน API เดิมที่ไม่ส่งเฉลย และตรวจคะแนนบน server เช่นเดิม

บทที่มีข้อสอบเดิมอยู่แล้ว (แม้เพียงชุดเดียว) จะไม่ถูกเขียนทับหรือเพิ่มต่อท้าย เพราะผลเดิมผูกกับบทเรียน ไม่ได้แยกเวอร์ชันข้อสอบ ต้องสร้างบทเรียนใหม่หากต้องการใช้ชุด AI โดยเก็บผลเดิมไว้ ไม่ลบผลผู้เรียนหรือข้อสอบเดิมอัตโนมัติ

## ตรวจสอบ

ใน `server`: `node --test tests/lesson-quiz-ai.test.js tests/lesson-quiz-secrecy.test.js` และ `npm test`

ใน `client`: `npm test`, `npm run lint`, `npm run build`

การทดสอบอัตโนมัติใช้ AI จำลอง ต้องทดสอบการสร้างจริงกับ Ollama อีกครั้ง

ข้อเขียนใช้ชนิด fill เดิม ไม่ต้องแก้ฐานข้อมูล ตรวจคำตอบตรงตัวโดยยุบช่องว่างและตัดช่องว่างหัวท้าย แต่แยกตัวพิมพ์ใหญ่/เล็ก ไม่รองรับเรียงความหรือโค้ดที่เขียนได้หลายวิธี สุ่มลำดับตอนสร้างในหน้าแอดมิน แล้วบันทึกลำดับนั้นไว้ ไม่สุ่มใหม่ขณะทำข้อสอบหรือรีเฟรช
