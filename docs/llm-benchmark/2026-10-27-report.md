## 1. ความถูกต้องของ Lumi — 90

25 คำถามครอบคลุมทั้ง 8 บท (range, list/tuple, input, dict, ลูป, ฟังก์ชัน, f-string, try, class, ไฟล์, lambda, `*args` ฯลฯ)

- ตอบได้ 25/25
- **ตรวจมือ:** ได้ 2 คะแนน 20 ข้อ, 1 คะแนน 5 ข้อ, 0 คะแนน 0 ข้อ → 45/50
- ตัวอย่างโค้ดในคำตอบ compile ผ่าน 15/16 (อันที่ไม่ผ่านคือตัวอย่าง IndentationError ที่ตั้งใจให้ผิด)

**5 ข้อที่ได้ 1 คะแนน:**

| ข้อ | ปัญหา |
|---|---|
| while กับ for | บอกว่า while "วนจนเงื่อนไขเป็นจริง" ซึ่ง**กลับกัน** (ที่ถูกคือวนขณะที่เงื่อนไขยังเป็นจริง) — ผิดสาระจุดเดียวที่พบ |
| 0.1 + 0.2 | อธิบายสาเหตุ (ฐานสอง) ถูก แต่คำแนะนำ "เปรียบเทียบด้วยเลขทศนิยมแทน" คลุมเครือ ไม่ได้บอก `round()` / `math.isclose()` |
| class กับ object | อุปมา "class เหมือนแม่น้ำ ถือกำเนิดสิ่งมีชีวิต" ชวนงง แม้โค้ดตัวอย่างถูก |
| self | ประโยคไทยขาดเป็นท่อน อ่านไม่รู้เรื่อง แม้โค้ดถูก |
| สลับค่า a, b | ใช้ตัวแปร temp ถูกต้อง แต่ไม่บอกวิธีของ Python `a, b = b, a` |

**หมายเหตุ:** ตัวตรวจคำสำคัญอัตโนมัติให้ 21/25 แต่ 1 ใน 4 ข้อที่ไม่ผ่าน (is กับ ==) ตอบถูก แค่ใช้คำที่ไม่อยู่ในรายการ

## 7. เขียนโค้ด — 85

ให้แก้โจทย์ Arcade ทั้ง 40 ข้อจากคำอธิบายภาษาไทย แล้วตรวจด้วย test case จริง

| ระดับ | ผ่าน |
|---|---:|
| ง่าย | 14/15 |
| กลาง | 12/15 |
| ยาก | 8/10 |
| **รวม** | **34/40** |

**ทั้ง 6 ข้อที่ไม่ผ่าน เขียนโค้ด "ถูกตามแบบที่คุ้นเคย" แต่ไม่ตรงกับสเปกของโจทย์:**
- **Remove Duplicates:** คืนจำนวน (แบบ LeetCode) แทน list ที่โจทย์สั่ง
- **Rotate Array:** แก้ list ในที่แล้วไม่ return
- **FizzBuzz Array:** ใส่ตัวเลขเป็น int แทน string
- **LRU Cache:** เช็ค `"GET"` ตัวพิมพ์ใหญ่ ขณะที่โจทย์ส่ง `"get"`
- **Palindrome Check:** ไม่ตัดช่องว่างออก
- **Count Unique Characters:** วงเล็บไม่ตรงกัน `len(set(s)}` (SyntaxError)

**ผลต่อเกม:** ข้อจำกัดนี้ทำให้รอบ "แก้คำตอบของ AI" และ "ตรวจคำตอบของ AI" ยังมีความหมาย เพราะคำตอบของ AI ผิดได้จริง
