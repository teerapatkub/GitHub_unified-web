# A07 — ใช้ไอเทมกับตนเองและตัวคูณคะแนนอย่างถูกต้อง

ที่มา: ticket ที่ผู้ใช้ส่งในแชตวันที่ 2026-10-08

Blocked by: A04, A06

- ตรวจการถือและใช้ไอเทมจริง รวมเกราะและตัวคูณ
- เก็บเอฟเฟกต์และเวลาหมดอายุบนเซิร์ฟเวอร์
- อ่านตัวคูณจากสถานะที่ตรวจสอบแล้ว ไม่รับธงจาก client
- ผ่านเมื่อ: ใช้ของซ้ำหรือปลอมตัวคูณไม่ได้ และคะแนนตรงกับผลไอเทมจริง

## ขอบเขตงานถัดไปตาม ticket ของผู้ใช้

- A08: ตรวจการโจมตี เป้าหมาย เฟส สถานะคัดออก เกราะ และการโอนเงิน; retry ต้องไม่โจมตี ใช้เกราะ หรือโอนเงินซ้ำ
- A09: ย้ายการซื้อ ใช้ของ และโจมตีของบอทไปเซิร์ฟเวอร์; แยกชนิดผู้เข้าร่วมโดยไม่ใช้ชื่อขึ้นต้น
- A10: คืนฉบับร่าง/คำตอบ กระเป๋า ร้าน เงิน เอฟเฟกต์ เวลา และสถานะคัดออก; แสดงสถานะบันทึก
- A11: อยู่ต่อ ออกจากห้อง โอนหัวห้อง และปิดห้องเมื่อไม่มีมนุษย์
- A12: แสดงองค์ประกอบคะแนน ตัวคูณ และรางวัลจากผลบันทึกจริง รองรับสองภาษาและมือถือ
- A13: integration กับ Auth จริง ไอเทมทุกชนิด หลายบัญชี หลายห้องไม่เกิน 20 คน เครือข่ายขัดข้อง และเอกสาร

## การตรวจรับ A07

ใช้ API ที่ผ่าน Auth จริงกับ PostgreSQL ชั่วคราว และตัวจบรอบที่ตกลงไว้ใน A04
ตรวจผ่านสถานะร้านและประวัติรอบ พร้อมลองหน้าเว็บจริงและรีเฟรชบนจอกว้าง/มือถือ
ไม่ได้เปลี่ยนฐานข้อมูล Supabase จริง และยังไม่ commit ตามคำสั่งผู้ใช้
