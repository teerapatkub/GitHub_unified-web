# คำตัดสินเป็นของ server ตัวเดียว การให้คะแนนแยกตามโหมด

ทั้งสามโหมด (บทเรียน, Arcade, Competitive Arena) เคยตัดสินเองว่าคำตอบถูกหรือผิด ด้วยกติกา
ที่ไม่ตรงกัน — Arcade ตัดสินในเบราว์เซอร์แล้วส่ง *คะแนน* ขึ้นมาให้ server บันทึก เราจึงแยกสองชั้น
ที่เคยถูกเรียกรวมกันว่า "การตรวจ" ออกจากกัน: **คำตัดสิน** (โค้ดให้ผลตรงกับเทสเคสหรือไม่) มีที่มา
ที่เดียวคือ server และเหมือนกันทุกโหมด ส่วน **การให้คะแนน** (XP, คะแนน 0–100, อันดับ) ยังต่างกัน
ตามโหมดโดยตั้งใจ ผลคือ Arcade ส่งขึ้นมาเฉพาะ *โค้ด* แล้ว server เป็นผู้รันเทส เรียกตัวตรวจคุณภาพโค้ด
และอ่านเวลาที่ใช้จากกำหนดเวลาของรอบที่ตัวเองเป็นคนตั้ง

เหตุผลหลักคือ Arcade เป็นโหมดเดียวที่จ่ายทองจากการแข่งกับคนอื่น ตราบใดที่ตัวเลขคะแนนมาจาก
เบราว์เซอร์ ผู้เล่นที่แก้คำขอเป็นจะชนะทุกแมตช์โดยไม่ต้องเขียนโค้ด และอันดับทั้งกระดานเชื่อถือไม่ได้
โปรเจคนี้ต้องเปิดให้ใช้งานจริง ไม่ใช่เดโม จึงยอมรับความเสี่ยงนั้นไม่ได้

## ทางเลือกที่พิจารณาแล้วไม่เลือก

- **ให้ Arcade ตัดสินในเบราว์เซอร์ต่อไปเพราะต้องการความเร็ว** — วัดจริงแล้วพบว่า server
  ตัดสินโจทย์ Arcade ใช้เวลา 139–423 มิลลิวินาที เทียบกับรอบละ 60 วินาที และระบบส่งอัตโนมัติ
  ที่ยิงล่วงหน้า 8 วินาที ข้อกังวลเรื่องความเร็วจึงไม่มีน้ำหนักพอ
- **ให้ server ตัดสินความถูกต้องอย่างเดียว แล้วเชื่อเวลากับคุณภาพโค้ดจาก client** — ยังเหลือ
  ช่องให้อ้างเวลาที่เหลือเกินจริง และจะต้องกลับมารื้อจุดเดิมซ้ำ
- **ยอมรับว่ามีตัวตรวจหลายตัวเพราะกติกาแต่ละโหมดต่างกัน** — สิ่งที่ต่างกันจริงคือการให้คะแนน
  ไม่ใช่คำตัดสิน และเคยมีตัวตรวจ 5 ตัวที่ตัดสินคำตอบเดียวกันไม่ตรงกันมาแล้ว

## ผลที่ตามมา

- Arcade **เก็บโค้ดไว้ก่อนแล้วตัดสินตอนปิดรอบ** สิ่งที่ผู้เล่นต้องทำทันเวลาคือส่งโค้ด ส่วนความเร็ว
  ในการตัดสินเป็นภาระของ server — ผู้เล่นจะไม่ตกรอบเพราะเครือข่ายของตัวเองช้า
- **Pyodide ในเบราว์เซอร์ยังอยู่ และตั้งใจให้อยู่** แต่ทำหน้าที่ *ลองรัน* เท่านั้น คือแสดงผลลัพธ์
  ที่โปรแกรมพิมพ์ออกมาทันที ไม่ตัดสินและไม่พูดคำว่าผ่าน/ไม่ผ่าน ใครที่เห็นแล้วคิดว่าเป็นโค้ดตกค้าง
  ที่ควรลบ โปรดอ่านย่อหน้านี้ก่อน
- ทุกการส่งคำตอบทำให้เกิดโปรเซส Python บน server เครื่องที่ติดตั้งจึงต้องมี Python และไลบรารี
  ที่โจทย์ใช้ครบ ซึ่งตัดโฮสต์ที่รันได้แต่ Node ออกจากตัวเลือกทั้งหมด
