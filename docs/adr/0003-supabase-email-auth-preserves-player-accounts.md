# แยกตัวตนสำหรับเข้าสู่ระบบออกจากบัญชีผู้เล่นเดิม

ย้ายวงจรอีเมลและรหัสผ่านไป Supabase Auth โดยคงบัญชีผู้เล่นเดิมและข้อมูลเกมทั้งหมด ผู้ใช้ยืนยันแล้วว่าต้องรับทั้งชื่อผู้ใช้และอีเมล คงรหัสผ่านเดิมหลังพิสูจน์เจ้าของบัญชีและยืนยันอีเมลหนึ่งครั้ง และคง Google เดิมไว้ในระยะนี้

ข้อเสนอคือเชื่อมตัวตนที่ตรวจสอบแล้วกับหมายเลขผู้เล่นเดิม แทนการเปลี่ยนหมายเลขผู้เล่นเป็น Auth UUID หรือสร้างบัญชีผู้เล่นใหม่ เพราะความก้าวหน้า เหรียญ และคลังของตกแต่งอ้างอิงหมายเลขเดิมอยู่ การตรงกันของอีเมลจากข้อมูลที่ client ส่งมาเพียงอย่างเดียวไม่ใช่หลักฐานความเป็นเจ้าของ

การคง Google เดิมหมายถึงต้องรองรับตัวตนที่ตรวจสอบได้จากสองวิธีเข้าสู่ระบบในช่วงเปลี่ยนผ่าน และทำให้ server เป็นผู้ตัดสินตัวตนกับสิทธิ์ ไม่ใช่ข้อมูลผู้ใช้ใน localStorage ผู้ใช้ยืนยันให้ดำเนินการตามแผนแล้ว การเปิดใช้จริงยังต้องผ่านการตั้งค่า SMTP, Redirect URLs และการทดสอบครบวงจร
