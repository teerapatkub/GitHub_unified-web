# บอท Arcade เขียนคำตอบจริง และถูกตรวจด้วยตัวตรวจเดียวกับผู้เล่น

## สิ่งที่ตัดสินใจ

บอทใน Arcade เคยไม่มีโค้ด มีแค่หลอดความคืบหน้า และคะแนนของบอทถูกสุ่มขึ้นตอนจบรอบ
ไอเทมโจมตีจึงแทบไม่มีผลกับบอท และผู้เล่นที่กดดูโค้ดบอทจะเจอข้อความว่า "บอทไม่มีโค้ดจริง"

ตอนนี้บอทแข่งแบบเดียวกับผู้เล่น:

- **คำตอบมาจากคลังที่ตรวจจริงแล้ว** (`server/arcade/bot-coder.js`)
  - ต่อโจทย์มีเฉลย, โค้ดตั้งต้นที่ไม่ได้แก้, และข้อผิดพลาดที่สร้างจากบรรทัดที่ผู้เล่นต้องเขียน
    (off-by-one, เครื่องหมายเปรียบเทียบกลับด้าน, เมธอดผิดตัว ฯลฯ)
  - ทุกแบบรันผ่าน `gradeSubmission` หนึ่งครั้งแล้ว cache ไว้ในหน่วยความจำ
  - บอทสุ่มเป้าสัดส่วนผ่านจาก `botSkillByDifficulty` เดิม แล้วเลือกคำตอบที่ผลจริงใกล้เป้าที่สุด
- **บอทพิมพ์ทีละตัวลง `draft_code`** พิมพ์ผิดแล้วลบแก้ หยุดคิดท้ายบรรทัด แล้วส่งคำตอบเองผ่าน
  `has_submitted`/`submitted_at` เหมือนผู้เล่น ไอเทมทุกตัวมีผลกับการพิมพ์นี้
- **ตอนจบรอบ ตรวจด้วยตัวตรวจจริง** จากโค้ดที่บอทส่ง (หรือร่างที่ค้างอยู่ถ้าหมดเวลา)
  และคิดเวลาจาก `submitted_at` เหมือนผู้เล่น

## สิ่งที่ยังต่างจากผู้เล่นโดยตั้งใจ

- ~~**คะแนนคุณภาพของบอทยังสุ่มจาก band ของระดับห้อง ไม่เรียก AI judge**~~
  **ถูกแทนที่โดย ADR 0006 (2026-10-20):** คลังคำตอบของบอทถูกตรวจด้วยตัวตรวจ Gemini ตัวเดียวกับผู้เล่น ครั้งเดียวต่อโจทย์
  - โควตาของตัวตรวจโค้ดเป็นของผู้เล่น (CLAUDE.md) บอท 4 ตัวจะทำให้เรียกเพิ่ม 4 เท่า
  - ระดับความยากจึงยังคุมได้ด้วยค่าเดียวใน config
- **บอทเลือกจากร้านค้าทุกชิ้น** ไม่ได้ถูกจำกัดด้วย 4 ชิ้นที่ร้านสุ่มให้ผู้เล่น (เหมือนเดิม)

## ทางสำรอง

- ถ้าห้องไม่มีโจทย์ที่สุ่มไว้ (ห้องรุ่นเก่า) หรือสร้างคลังคำตอบไม่สำเร็จ (เช่น Python ใช้ไม่ได้)
  บอทกลับไปใช้หลอดความคืบหน้าและคะแนนสังเคราะห์ (`synthesizeBotRoundScore`)
- แมตช์จะไม่ค้างเพราะบอท

## ทางเลือกที่ไม่เลือก

- **ให้ AI เขียนโค้ดสดทุกรอบ** เป็นธรรมชาติที่สุด แต่บอท 4 ตัว × 4 รอบ = 16 การเรียกต่อแมตช์
  - กินโควตา ช้า และถ้า API ล่ม บอทจะไม่มีโค้ด
- **คงคะแนนสังเคราะห์ แต่ให้ไอเทมลดคะแนน** (สิ่งที่ทำใน d3d3421)
  - แก้ได้แค่ Fog/Freeze และโค้ดของบอทยังไม่มีอยู่จริง

## ผลที่ตามมา

- สมดุลวัดด้วย `npm run sim:bots`
  - คะแนนเฉลี่ยต่อรอบของบอทที่ไม่โดนโจมตีต่างจากเดิมไม่เกิน ±10% ทุกระดับ
  - ง่าย +3%, ดั้งเดิม +3%, ปานกลาง +1%, ยาก −6%
- บอท "ยอมแพ้" (ไม่แก้โค้ดตั้งต้น) ได้ราว 7–13% ของรอบ
  - ไม่ส่งทันที แต่ปล่อยให้หมดเวลาแล้วระบบส่งให้ เหมือนผู้เล่นที่ติด
  - บอทที่ฝีมือต่ำส่วนใหญ่จะส่งคำตอบที่ผิดแต่ได้ลองเขียน
- เริ่มแมตช์ต้องตรวจคลังคำตอบราว 1.5 วินาทีต่อโจทย์
  - บอทเริ่มพิมพ์ช้าเท่านั้น ("อ่านโจทย์")
  - cache อยู่จนกว่า server restart ถ้าแก้โจทย์ใน DB บอทจะใช้คลังเก่าจนกว่าจะ restart
- ผู้เล่นที่ส่งคำตอบแล้วหรือตกรอบดูร่างของบอทได้ (กติกา `mayWatch` เดิม)
  ดังนั้นเฉลยไม่หลุดถึงคนที่ยังเขียนอยู่
