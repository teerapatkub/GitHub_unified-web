# 23: รอบ "ตรวจคำตอบ AI"

**What to build:** ในห้องผสม รอบที่สุ่มรูปแบบอาจได้เป็นรอบตรวจคำตอบ AI
- ผู้เล่นเห็นคำตอบ 3–4 แบบที่ติดป้าย "จาก AI" แล้วเลือกคำตอบที่ผ่านทุกเทส
- หลังจบรอบ ถ้าเลือกผิด จะเห็นว่าคำตอบที่เลือกไม่ผ่านเทสไหน
- บอทเลือกคำตอบตามบุคลิกของบอท

**สิ่งที่ตัดสินใจแล้ว:**
- **ตัวเลือก:** มีเฉลยหนึ่งตัว ที่เหลือเป็นคำตอบผิดจาก bot-coder
- **การตัดสิน:** server รันตัวตรวจกับทุกตัวเลือกแล้วตัดสินจากผลนั้น ไม่เชื่อข้อมูลที่เก็บไว้ว่าตัวไหนถูก
- **ลำดับตัวเลือก:** สลับต่อผู้เล่นแต่ละคน
- **คะแนน:** คิดแบบเดียวกับ ticket 22

อ้างอิง: Spec 0005 Track G3

**Blocked by:** 22 (ใช้ UI ตัวเลือกและ payload แบบเดียวกัน)

**Status:** ready-for-agent

- [ ] เทส HTTP:
  - เลือกถูกหรือผิดได้คะแนนตามกติกา
  - ผลหลังจบรอบบอกเทสที่ตัวเลือกนั้นไม่ผ่าน
- [ ] เทส HTTP: ผู้เล่นสองคนในห้องเดียวกันได้ลำดับตัวเลือกต่างกัน แต่ระบบตัดสินถูกทั้งสองคน
