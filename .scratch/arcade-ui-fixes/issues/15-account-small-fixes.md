# 15: แก้เล็กๆ ในระบบบัญชี

**What to build:** แก้จุดเล็กๆ ที่ทำให้การสมัครและการเริ่มใช้งานสะดุด

- **U5:** ตัวเลือก "เคยเขียนภาษาอื่น" ต้องได้ระดับเริ่มต้นต่ำกว่า "เขียน Python ได้อยู่แล้ว"
  - ค่าที่เสนอคือ `level_value` 5 ต้องยืนยันกับทีมก่อน
  - แก้ใน seed logic ไม่แก้ฐานข้อมูลด้วยมือ
- **U7:** ถ้าเปิดหน้า login ตอน server ยังบูตไม่เสร็จ หน้าต้องขึ้นว่า "กำลังเชื่อมต่อ…" และลองใหม่เองเป็นระยะเมื่อได้ 503 ไม่ใช่ขึ้นแถบแดง
- **U9:** ขั้นของทัวร์ Lumi ที่พูดถึง "ตัวเลข LV." ต้องชี้ไปที่สิ่งที่มีอยู่จริงบนหน้า จะแก้ข้อความในทัวร์ หรือเพิ่ม LV บนแถบเมนูก็ได้
- **U10:** ข้อความหลังกดลืมรหัสผ่านต้องอ่านเข้าใจง่ายสำหรับคนทั่วไป เช่น "ถ้ามีบัญชีนี้อยู่ เราส่งลิงก์ไปที่อีเมลแล้ว"
- **U11:** ความสำเร็จพื้นฐาน เช่น "โค้ดแรกผ่าน" ต้องมีป้าย "ง่าย"
- **แบบสอบถาม:** ห้ามดึงโปรไฟล์ซ้ำทุกครั้งที่ render (ตอนนี้ดึงประมาณ 10 ครั้ง)
