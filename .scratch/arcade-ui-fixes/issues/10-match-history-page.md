# 10: ประวัติแมตช์แยกหน้า

**What to build:** ผู้เล่นที่เล่นไปแล้ว 100 แมตช์ เข้าล็อบบี้ Arcade แล้วต้องเห็นการค้นหา/สร้างห้องและรายการห้องก่อน ตามด้วยการ์ดสถิติ แล้วจึงเป็นการ์ดประวัติ

**การ์ดประวัติในล็อบบี้**
- แสดง 3 แมตช์ล่าสุด แมตช์ละหนึ่งบรรทัด: ชื่อห้อง อันดับ คะแนนรวม ทอง
- มีปุ่ม "ดูประวัติทั้งหมด (N แมตช์)"
  - ไปที่หน้าประวัติแมตช์ของ Arcade ซึ่งเป็น route ใหม่
  - ต้องเลเวล 10 เหมือนล็อบบี้

**หน้าประวัติแมตช์**
- **ลำดับและการโหลด:** เรียงจากแมตช์ใหม่สุด โหลดทีละ 20 แมตช์ มีปุ่ม "โหลดเพิ่ม"
- **ตัวกรอง:** กรองตามความยากและจังหวะของห้องได้
- **รายละเอียด:** กดแมตช์ไหนก็เห็นรายรอบ ใช้แผงเดียวกับหน้าสรุปผล
- **วันที่:** แสดงตามภาษาที่เลือก เช่น "25 ต.ค. 2569 22:02" (แก้ A7)
- **ยังไม่เคยเล่น:** แสดงข้อความชวนสร้างห้องแรก
- **ปุ่มย้อนกลับของเบราว์เซอร์:** พากลับไปล็อบบี้

**API:** `GET /api/arcade/players/:user_name/history`
- **พารามิเตอร์ที่รับ:** `limit` (1–50 ค่าเริ่มต้น 10), `before` (match id), `difficulty`, `round_duration_mode`
- **ฟิลด์ที่ตอบเพิ่ม:** `next_before` (เป็น null เมื่อไม่มีหน้าถัดไป) และ `total_matches`
- **สิทธิ์:** ตอบเฉพาะบัญชีของผู้เรียก
- **การแบ่งหน้า:** ทำใน SQL โดยเลือก match id ของหน้านั้นก่อน แล้วค่อยดึงแถวรายรอบ

อ้างอิง: Spec 0005 Track C, คำขอของผู้ใช้, บั๊ก A7

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
