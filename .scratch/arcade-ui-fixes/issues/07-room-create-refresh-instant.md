# 07: สร้างห้องและรีเฟรชแล้วไม่เห็นหน้าค้าง

**What to build:** แก้ 4 เรื่องที่ทำให้ห้องดูค้างหรือผิดหลังสร้างห้องหรือรีเฟรช

- **สร้างห้อง (A8):** ผู้เล่นต้องเห็นตัวเองเป็นหัวห้องและ "1 / 5" ทันที ไม่ใช่ "0 / 5" ที่ไม่มีชื่อหัวห้อง วิธีทำคือใช้ข้อมูลจากคำตอบของการสร้างห้องเลย ไม่ต้องรอ poll รอบแรก
- **รีเฟรชระหว่างแข่ง (A8):** ขึ้นสถานะ "กำลังกลับเข้าแมตช์" แทนที่จะโชว์ล็อบบี้อยู่ประมาณ 6 วินาที
- **ฟอร์มสร้างห้อง (A9):** ค่าเริ่มต้นต้องครบทุกช่องเสมอ รวมถึงจังหวะและความยาก ใช้ชุดค่าเริ่มต้นชุดเดียวทั้งตอนเปิดฟอร์มครั้งแรกและตอน reset
- **poll รายการห้อง (A11):** หยุดดึงรายการห้องทั้งหมดเมื่อผู้เล่นอยู่ในห้องแล้ว และเริ่มดึงอีกครั้งเมื่อกลับล็อบบี้

อ้างอิง: Spec 0005 Track A, บั๊ก A8, A9, A11
