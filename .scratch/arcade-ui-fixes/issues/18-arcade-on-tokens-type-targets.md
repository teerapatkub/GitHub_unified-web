# 18: ย้าย Arcade มาใช้ token พร้อมปรับขนาดตัวอักษรและปุ่ม (migrate)

**What to build:** หลังทำ ticket นี้ หน้า Arcade จะเป็นแบบนี้:
- **ธีม:** สีของหน้าเปลี่ยนตามธีมที่ผู้เล่นสวม
- **ป้ายกำกับ:** อ่านได้โดยไม่ต้องเพ่ง ขนาดอย่างน้อย 12px และ contrast อย่างน้อย 4.5:1
- **ปุ่ม:** กดด้วยนิ้วได้ ขนาดอย่างน้อย 32px ส่วนปุ่มหลักอย่างน้อย 44px เช่น "🔄 รีเฟรชรายการ" และ "← กลับหน้าหลัก"

งานหลักคือเปลี่ยนสีดิบของ Tailwind ใน widget ของ Arcade ไปใช้ token จาก ticket 17
