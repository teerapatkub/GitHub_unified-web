# 06: ล้างสถานะผู้สังเกตการณ์ และเพิ่มปุ่มออกเมื่อตกรอบ

**What to build:** ป้าย "โหมดผู้สังเกตการณ์" ขึ้นเฉพาะตอนที่ผู้เล่นตกรอบในแมตช์ปัจจุบัน ป้ายต้องไม่ค้างอยู่ในกรณีเหล่านี้:
- หน้าสรุปของคนที่ไม่ได้ตกรอบ
- หลังจบแมตช์ หรือตอนกลับล็อบบี้
- แมตช์ถัดไป

ผู้เล่นที่ตกรอบมีปุ่มออกจากห้องที่กดได้ทันที ไม่ต้องรอให้แมตช์จบ

สถานะผู้สังเกตการณ์ต้องผูกกับ match id และถูกล้างเมื่อเปลี่ยนเฟสหรือเมื่อ match id เปลี่ยน

อ้างอิง: Spec 0005 Track A, บั๊ก A3 และส่วนปุ่มออกของ A4 (ส่วนเนื้อหาของหน้าผู้ชมอยู่ใน ticket 24)

**Blocked by:** None (can start immediately)

**Status:** done (2026-10-26, see project_logs/2026-10-26/0400-tickets-04-10-arcade-phase-1.md)
