# 06: ล้างสถานะผู้สังเกตการณ์ และเพิ่มปุ่มออกเมื่อตกรอบ

**What to build:** ป้าย "โหมดผู้สังเกตการณ์" ขึ้นเฉพาะตอนที่ผู้เล่นตกรอบในแมตช์ปัจจุบัน ป้ายต้องไม่ค้างอยู่ในกรณีเหล่านี้:
- หน้าสรุปของคนที่ไม่ได้ตกรอบ
- หลังจบแมตช์ หรือตอนกลับล็อบบี้
- แมตช์ถัดไป

ผู้เล่นที่ตกรอบมีปุ่มออกจากห้องที่กดได้ทันที ไม่ต้องรอให้แมตช์จบ

สถานะผู้สังเกตการณ์ต้องผูกกับ match id และถูกล้างเมื่อเปลี่ยนเฟสหรือเมื่อ match id เปลี่ยน

อ้างอิง: Spec 0005 Track A, บั๊ก A3 และส่วนปุ่มออกของ A4 (ส่วนเนื้อหาของหน้าผู้ชมอยู่ใน ticket 24)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] เทส client (logic ล้วน): สถานะผู้สังเกตการณ์เป็นเท็จหลังเปลี่ยนเป็นเฟสผลลัพธ์หรือล็อบบี้ และเมื่อ match id เปลี่ยน
- [ ] ทดสอบผ่าน dev server: เมื่อตกรอบต้องเห็นปุ่มออก กดแล้วกลับล็อบบี้ และผู้เล่นที่เหลือในห้องแข่งต่อได้
- [ ] ทดสอบผ่าน dev server: จบแมตช์ที่อันดับ 2 โดยไม่ได้ตกรอบ หน้าสรุปต้องไม่มีป้ายผู้สังเกตการณ์
- [ ] กด "อยู่ในห้องเดิมต่อ" แล้วเริ่มแมตช์ใหม่ ต้องไม่มีป้ายค้าง
- [ ] `npm run test:spectator` และ `npm run test:arcade` ผ่าน
