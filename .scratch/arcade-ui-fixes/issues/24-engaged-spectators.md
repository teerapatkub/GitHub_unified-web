# 24: ผู้ชมที่มีส่วนร่วม

**What to build:** ผู้เล่นที่ตกรอบจะมีสิ่งให้ทำแทนการดูหน้าว่าง:
- **สถานะสด:** เห็นผู้เล่นที่ยังรอดแต่ละคนว่า ผ่านกี่เทส ส่งคำตอบแล้วหรือยัง และกำลังโดน debuff อะไร
- **ทายผู้รอด:** ก่อนรอบชิง ทายได้หนึ่งครั้งว่าใครจะรอดเป็นคนสุดท้าย ทายถูกได้ทองเล็กน้อย
  - ค่าที่เสนอคือ 30 ทอง ต้องยืนยันกับผู้ใช้ก่อน
- **เชียร์:** ส่งอีโมจิในแชทของห้องได้ แต่จำกัดความถี่
- **ไม่กระทบคนที่ยังแข่ง:** การทายไม่มีผลต่อคะแนนหรือเงินในเกมของผู้เล่นที่ยังแข่งอยู่

**สิ่งที่ตัดสินใจแล้ว:**
- **ข้อมูลที่ส่งให้ผู้ชม:** endpoint สถานะผู้ชมให้แค่ข้อมูลสาธารณะ ไม่ส่งโค้ดของผู้เล่นที่ยังแข่ง
- **การเก็บคำทาย:** หนึ่งแถวต่อผู้ชมหนึ่งคนต่อหนึ่งแมตช์
- **การจ่ายรางวัล:** จ่ายตอน settle ผ่าน receipt เดิม เพื่อกันจ่ายซ้ำ
- **schema:** แก้ใน `server/db.js` เท่านั้น

อ้างอิง: Spec 0005 Track G4, บั๊ก A4

**Blocked by:** 06 (สถานะผู้สังเกตการณ์ต้องถูกต้องก่อน)

- [ ] เทส HTTP: ทายครั้งที่สองในแมตช์เดียวกันได้ 409 และทายผู้เล่นที่ตกรอบไปแล้วได้ 400
