# 22: รอบ "ทายผลลัพธ์"

**What to build:** รอบแรกของห้องผสมเป็นรอบสั้น 15–20 วินาที
- ผู้เล่นเห็นโค้ดสั้นๆ กับ input แล้วแตะเลือกว่าโค้ดจะพิมพ์อะไร ไม่ต้องพิมพ์เอง จึงเล่นบนมือถือได้
- ไอเทมโจมตียังมีผล:
  - Ink Fog บังโค้ด
  - Freeze และ Mirror Code มีผลกับช่องตอบ
- บอทเลือกคำตอบถูกตามความน่าจะเป็นที่ขึ้นกับบุคลิกของบอทและระดับห้อง

**สิ่งที่ตัดสินใจแล้ว:**
- **ที่มาของข้อมูล:**
  - โค้ดที่แสดงมาจากโจทย์ stdio ที่ตรวจอัตโนมัติได้
  - ผลลัพธ์ที่ถูกได้จากการรันผ่าน python runner ตอน seed
  - ตัวเลือกที่ผิดมาจากผลลัพธ์ของคำตอบผิดของ bot-coder บน input เดียวกัน
- **การตัดสิน:**
  - เทียบสตริงหลังกลบ prompt ด้วยกฎเดียวกับตัวตรวจ
  - ส่งคำตอบผ่าน endpoint ส่งคำตอบของ Arcade ตัวเดิม โดยใช้ payload ตามรูปแบบรอบ
- **คะแนน:** ตอบถูกได้คะแนนคุณภาพเต็ม ตอบผิดได้ 0
- **ไอเทมที่ใช้ไม่ได้ในรอบนี้:** ร้านต้องแสดงเหตุผลว่าทำไมใช้ไม่ได้
