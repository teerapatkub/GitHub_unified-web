# 01: บันทึกตั้งค่าห้องแล้วรหัสผ่านไม่หาย

**What to build:** หัวห้อง Arcade เปิดหน้าตั้งค่า แก้อะไรก็ได้แล้วกดบันทึก ห้องที่มีรหัสผ่านต้องยังมีรหัสผ่านเดิม จะเปลี่ยนเป็นห้องสาธารณะได้ก็ต่อเมื่อกดปุ่ม "ลบรหัสผ่าน" ที่แยกไว้ต่างหาก หน้าตั้งค่าบอกว่าตอนนี้ห้องมีรหัสผ่านหรือไม่ โดยไม่โชว์ตัวรหัส

endpoint แก้ตั้งค่าห้องรับค่าได้สามแบบ:
- ไม่ส่งฟิลด์รหัสผ่าน: คงรหัสเดิม
- ส่งสตริงที่ไม่ว่าง: ตั้งรหัสใหม่ (เก็บเป็น bcrypt)
- ส่งธงลบรหัสผ่าน: ลบรหัส

สตริงว่างไม่ใช่คำสั่งลบอีกต่อไป ข้อมูลห้องที่ส่งให้ client มีธง `is_password_protected` (ชื่อเดียวกับรายการห้อง) แต่ไม่มี hash
