# 03: สลับลำดับตัวเลือกในแบบวัดระดับ

**What to build:** ผู้เรียนใหม่ที่ทำแบบวัดระดับจะเห็นลำดับตัวเลือกและลำดับข้อไม่ซ้ำกันในแต่ละครั้ง ผลคือคำตอบที่ถูกไม่ได้อยู่ตัวแรกเสมอ และกดตัวเลือกแรกทุกข้อแล้วไม่ได้เลเวล 10 อีก

- server เป็นคนสลับลำดับตอนส่งชุดคำถาม
- การตรวจยังเทียบข้อความของตัวเลือกเหมือนเดิม (ไม่ได้ใช้ตำแหน่ง) จึงไม่กระทบคำตัดสิน
- ข้อมูลที่ส่งให้ client ต้องไม่มีอะไรบอกว่าตัวเลือกไหนถูก

อ้างอิง: Spec 0005 ระยะ 0, บั๊ก U4
