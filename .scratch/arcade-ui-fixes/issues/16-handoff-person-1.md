# 16: บันทึกส่งต่อให้ Person 1

**What to build:** ส่งรายการปัญหาที่อยู่ในไฟล์ของ Person 1 ให้ครบ ทุกข้อมีหลักฐานและข้อเสนอวิธีแก้ เพื่อให้ Person 1 แก้เองก่อน merge โดย Person 3 ไม่แก้ไฟล์เหล่านี้

รายการที่ต้องเขียน:
- **U3:** หน้าบทเรียนบอก 0 / 120 XP แต่โปรไฟล์บอก 0 / 1000 XP เสนอให้ทั้งสองหน้าอ่านเลเวลและ XP ที่ต้องใช้จาก server ที่เดียวกัน
- **U6:** ผ่านแบบวัดระดับแล้วไม่เห็นคะแนน และยังต้องเริ่มที่บทที่ 1
- **เมนูย่อยของบทเรียนบนมือถือ:** เป็นไอคอนอย่างเดียว ไม่มีชื่อกำกับ
- **ปุ่มบทเรียนที่กดไม่ได้:** contrast แค่ 1.2:1
- **ช่องกรอกในแบบทดสอบของบทเรียน:** ไม่มี label
- **หน้าสอบเลื่อนขั้นที่เลเวล 10:** แสดง 0/0 แต่ยังมีปุ่มส่งตรวจ
- **workspace บนมือถือ:** พื้นที่ editor เหลือน้อย และปุ่ม Lumi ทับมุม editor
- **บั๊กเดิมที่ยังค้าง:** `message` กับ `messages`

อ้างอิง: Spec 0005 Track F

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
