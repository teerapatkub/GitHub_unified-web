# 02: ลดจำนวนผู้เล่นสูงสุดต่ำกว่าคนในห้องไม่ได้

**What to build:** ถ้าในห้องมีคนอยู่ 5 คน หัวห้องเลือก "2 คน" ไม่ได้

- ในหน้าตั้งค่า ปุ่มจำนวนที่ต่ำกว่าคนในห้องถูกปิด และมีคำอธิบายว่าทำไม
- ถ้ามีคำขอแบบนี้ส่งตรงมาที่ server ให้ตอบ 409 พร้อมข้อความภาษาไทย ห้ามปรับค่าให้เองเงียบๆ

ผลคือห้องจะไม่ขึ้นตัวเลขอย่าง "5 / 2 คน" อีก
