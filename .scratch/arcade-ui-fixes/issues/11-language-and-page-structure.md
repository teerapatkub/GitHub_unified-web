# 11: ภาษาและโครงหน้า

**What to build:**
- **จำภาษาที่เลือก (U1):**
  - ถ้าผู้เรียนสลับเป็น EN แล้วรีเฟรชหรือเปิดหน้าใหม่ ต้องยังเป็น EN
  - ระบบต้องอ่านภาษาที่ผู้เรียนเลือกไว้ก่อนค่าเริ่มต้น
  - ถ้ายังไม่เคยเลือกภาษา ให้ใช้ภาษาไทย
- **`lang`:** attribute ภาษาของเอกสารต้องเปลี่ยนตามภาษาทุกครั้ง โปรแกรมอ่านหน้าจอจะได้อ่านภาษาไทยด้วยเสียงไทย
- **ชื่อแท็บ:** ทุก route ตั้งชื่อแท็บเป็น "<ชื่อหน้า> · PyArena" แทน "Python Coder Game"
- **landmark:** ทุกหน้าของผู้เรียนมี `<main>` และ `h1` อย่างละหนึ่งอัน

ไฟล์ที่แก้เป็นไฟล์กลางที่ทุกคนในทีมใช้ ต้องแจ้งทีมและบันทึกใน handoff ก่อน merge
