# 08: หน้าสรุปแสดงทองจากความสำเร็จ

**What to build:** หน้าสรุปหลังจบแมตช์ต้องแสดงทองทั้งหมดที่ได้จากแมตช์นั้น โดยมี:
- บรรทัดรางวัลตามอันดับ
- บรรทัดแยกสำหรับแต่ละความสำเร็จที่ปลดล็อกในแมตช์นั้น พร้อมจำนวนทอง
- ยอดรวม

ยอดรวมต้องตรงกับทองที่เพิ่มขึ้นในบัญชีจริง

**ที่ทำจริง:** ความสำเร็จถูกตรวจหลัง settle แบบแยกขั้น (ticker) ไม่ได้อยู่ในคำตอบ HTTP ใด จึงเก็บผลไว้ที่ `arcade_reward_receipts.achievement_rewards` (migration ใหม่ 202610260001) แล้วส่งให้ผู้เล่นทาง `viewer_reward` ใน poll ของห้อง

อ้างอิง: Spec 0005 Track A, บั๊ก A10

**Blocked by:** None (can start immediately)
