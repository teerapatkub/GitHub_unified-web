# 08: หน้าสรุปแสดงทองจากความสำเร็จ

**What to build:** หน้าสรุปหลังจบแมตช์ต้องแสดงทองทั้งหมดที่ได้จากแมตช์นั้น โดยมี:
- บรรทัดรางวัลตามอันดับ
- บรรทัดแยกสำหรับแต่ละความสำเร็จที่ปลดล็อกในแมตช์นั้น พร้อมจำนวนทอง
- ยอดรวม

ยอดรวมต้องตรงกับทองที่เพิ่มขึ้นในบัญชีจริง คำตอบของการ settle แมตช์จึงต้องส่งรายการความสำเร็จที่ปลดล็อกกลับมาด้วย

อ้างอิง: Spec 0005 Track A, บั๊ก A10

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] เทส HTTP: แมตช์ที่ปลดล็อกความสำเร็จ คำตอบของ settle มีรายการความสำเร็จพร้อมทองของแต่ละรายการ
- [ ] เทส HTTP: settle ซ้ำแล้วไม่จ่ายซ้ำ (ใช้ receipt เดิม) และรายการที่ตอบกลับไม่ซ้ำ
- [ ] ยอดรวมบนหน้าสรุปเท่ากับทองในบัญชีหลังจบแมตช์ลบด้วยทองก่อนแมตช์ (ตรวจกับฐานจริง)
- [ ] `arcade-settlement.test.js`, `arcade-rewards.test.js` และ `npm run test:arcade` ผ่าน
