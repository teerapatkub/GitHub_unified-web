# 12: ร้านค้า: ปุ่มอ่านชัด โหลดเร็ว และลบของทดสอบ

**What to build:** แก้ร้านค้าให้ผู้เล่นใช้ได้สะดวกขึ้น:
- **ปุ่มอ่านชัด:** ปุ่ม "ซื้อ", ปุ่ม "กำลังสวมใส่" และป้าย "มีแล้ว" ต้องมี contrast อย่างน้อย 4.5:1 (ตอนนี้ได้ 2.1–2.5:1)
- **โหลดเร็ว:**
  - เปิดหน้าครั้งหนึ่งให้ดึง items, inventory และ sets อย่างละครั้ง (ตอนนี้ดึงซ้ำ 3 รอบ)
  - หน้าต้องโหลดเสร็จภายใน 2 วินาทีบนเครื่อง dev (ตอนนี้ประมาณ 7 วินาที)
- **ช่องค้นหา:** มี label
- **ของทดสอบ (U8):** ลบสินค้าทดสอบ "he" และ "Heart" ออกจากร้าน

**วิธีลบสินค้าทดสอบ:** ใช้สคริปต์ที่มี dry run ตรวจทั้งฐานทดสอบและ production ก่อนลบ **ห้ามลบใน production จนกว่าผู้ใช้จะยืนยัน**

อ้างอิง: Spec 0005 Track D/E, audit P1 ข้อ 1, audit P2 ข้อ 13, บั๊ก U8

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
