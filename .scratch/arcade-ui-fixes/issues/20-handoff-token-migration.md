# 20: บันทึกส่งต่อให้ Person 1/2 ย้ายหน้าของตัวเองมาใช้ token

**What to build:** เขียนคู่มือสั้นๆ ให้ Person 1 และ Person 2 ย้ายหน้าของตัวเองมาใช้ token แบบเดียวกับที่ Arcade ทำใน ticket 18 คู่มือต้องมี:
- ตารางแปลงจากสีดิบเป็น token
- ขนาดขั้นต่ำของตัวอักษรและปุ่ม
- วิธีตรวจผลด้วยสคริปต์ audit-page
- รายการไฟล์ของแต่ละคน พร้อมจำนวนสีดิบที่ยังเหลือ

ขั้น **contract** คือการลบชื่อ token เดิมทั้ง 4 ชุด ทำได้หลังทุกคนย้ายเสร็จ และไม่อยู่ใน ticket ชุดนี้
