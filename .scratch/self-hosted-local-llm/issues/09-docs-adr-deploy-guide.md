# 09: เอกสาร (ADR 0009, คู่มือ deploy, CLAUDE.md)

**What to build:**

ผู้ตรวจโครงงานและสมาชิกทีมอ่านแล้วเข้าใจว่าระบบ deploy อย่างไร ทำไมเลือกแบบนี้ และต้องทำอะไรบ้างก่อนวันสอบ

- **ADR 0009 (deploy ด้วย Docker บนเครื่องที่ดูแลเอง และใช้ LLM ในเครื่อง):** แทน ADR 0008 ในส่วน Render, cron และ Gemini
- **คู่มือ deploy ใหม่:** แทนคู่มือ Render มีหัวข้อดังนี้
  - ติดตั้งครั้งแรก
  - ตาราง env
  - เปิดเครื่องก่อนวันสอบ
  - ย้ายไป VM ของ มข.
  - เปลี่ยนไปใช้โดเมน kku.ac.th
- **CLAUDE.md:**
  - ตาราง AI เปลี่ยนเป็น Ollama 3 งาน แต่ละงานมี env ของตัวเอง
  - กฎ "แยกโมเดล" เปลี่ยนเป็น "ตั้งชื่อโมเดลแยกต่องาน, ห้าม hard-code, ห้ามใช้ API key ของ AI ภายนอก"
