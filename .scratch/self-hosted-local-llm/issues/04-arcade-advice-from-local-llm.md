# 04: คำแนะนำหลังแมตช์ Arcade ด้วย LLM ในเครื่อง

**What to build:** หลังแมตช์จบ ผู้เล่น Arcade เปิดประวัติรอบแล้วได้คำแนะนำที่ LLM ในเครื่องเขียน แทน Gemini

- เรียกผ่านตัวเรียกจาก ticket 01 ด้วย `LLM_ADVICE_MODEL`
- พฤติกรรมเดิมต้องคงไว้ทั้งหมด:
  - rate limit
  - ขอได้ครั้งเดียวต่อแถวประวัติ
  - กันคำขอซ้ำที่ยังทำงานอยู่
  - ถ้า LLM ล้มเหลว ใช้ผลวัดในเครื่องแทน
- คะแนนคุณภาพและเวลาปิดรอบไม่เปลี่ยน ยังเป็นไปตาม ADR 0007
- เอา SDK ของ Gemini ออกจาก dependency ของ server

อ้างอิง: Spec 0004, user story 14–16

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] judge ของ Arcade สร้างคำแนะนำผ่านโมดูลตัวเรียก LLM และไม่มีโค้ดของ Gemini เหลือ
- [ ] เทสของ judge Arcade ที่มีอยู่ปรับให้ใช้ generator ใหม่ แล้วผ่าน
- [ ] เทสผ่าน Ollama ปลอม ยิง endpoint คำแนะนำของประวัติรอบจริง:
  - [ ] ตัวปลอมตอบสำเร็จ → ได้ข้อความจากตัวปลอม
  - [ ] ตัวปลอมล้มเหลว → ได้ผลวัด
  - [ ] ขอซ้ำ → ได้ค่าที่เก็บไว้ และตัวปลอมไม่ถูกเรียกอีก
- [ ] `npm run test:arcade`, calibration (40/40 ได้ 95+) และ `npm run sim:bots` ผ่าน
- [ ] เล่นทดสอบ Arcade 1 แมตช์บน dev server แล้วประวัติรอบโหลดคำแนะนำได้
