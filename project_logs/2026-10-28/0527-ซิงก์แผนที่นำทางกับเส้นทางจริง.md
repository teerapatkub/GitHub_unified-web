# ซิงก์แผนที่นำทางกับเส้นทางจริง

**วันที่และเวลา:** 2026-10-28 05:27 น.

## สรุปการเปลี่ยนแปลง

- `client/src/pages/MiNi_Game.jsx` — สร้างเส้นเชื่อมในแผนที่จาก `next_dialogue_id` แล้วหา subtopic เจ้าของ dialogue ID นั้น เช่นเดียวกับเส้นทางกด choice
- node ปัจจุบันแสดงชื่อจาก `currentMissionCopy.title` ให้ตรงกับชื่อโจทย์ที่แสดงในหน้าเล่น
- node ที่ยังไม่ถึงแสดงชื่อพร้อมไอคอนล็อก ไม่ซ่อนชื่อ node
- `docs/handoff-to-person-1.md` — บันทึกผลกระทบให้เจ้าของ Mini Game ตรวจ

## เหตุผล

แผนที่เดิมอนุมานปลายทางจาก `branch_key`/`exercise_order` แต่ `handleDialogueChoice` ใช้ `next_dialogue_id` เพื่อนำทาง ทำให้ข้อมูลเส้นทางในแผนที่ไม่ตรงกับการทำงานจริง นอกจากนี้หัวข้อปัจจุบันบนแผนที่ใช้ชื่อด่านต้นฉบับ แทนชื่อสาขาที่หน้าปัจจุบันแสดง

## ผลกระทบที่อาจมีต่อส่วนอื่น

ไม่มีผลกับการเปลี่ยนเส้นทางจริง; ปรับเฉพาะการคำนวณ/แสดงแผนที่ให้สะท้อนเส้นทางจริงและข้อมูลปัจจุบัน

## ผลตรวจสอบ / สิ่งที่เหลือ

- ESLint เฉพาะ `MiNi_Game.jsx` ไม่มี error; มี warning dependency ของ `useEffect` เดิม
- `npm run build` ผ่าน
- ยังไม่ได้ทดสอบเส้นทางใน browser หลัง login จึงควรตรวจ node/เส้นทางของ choice จริงในเกม
