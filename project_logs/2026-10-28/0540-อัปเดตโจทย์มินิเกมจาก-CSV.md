# อัปเดตโจทย์มินิเกมจาก CSV

**วันที่และเวลา:** 2026-10-28 05:40 น.

## สรุปการเปลี่ยนแปลง

- นำ `Downloads/mini_game_exercises_rows.csv` ไปอัปเดต source rows ของ Mini Game บท 1 ใน `problems` สำหรับ entry IDs 1–7
- อัปเดต title/description สองภาษา, starter/solution code และ test cases โดยแปลง `input` array เป็น stdin string ที่ grader ใช้
- ตามคำยืนยันผู้ใช้ ลบเฉพาะ `rules` และ `expected_format` เก่าของโจทย์ VAT จาก `problem_modes.extra`
- ไม่เปลี่ยน ID, registration/order/rewards, dialogues, choices, files, progress หรือ submissions
- `docs/handoff-to-person-1.md` — แจ้งการเปลี่ยนข้อมูลและข้อควรระวังเรื่อง progress/snapshot

## เหตุผล

ข้อมูลใน compatibility view `mini_game_exercises` เป็น VIEW จาก `problems` + `problem_modes`; ต้องอัปเดตตารางต้นทาง ไม่สามารถเขียนลง view โดยตรง

## ผลกระทบที่อาจมีต่อส่วนอื่น

ผู้เล่นเห็นโจทย์ Doki Doki ชุดใหม่ในบท 1; progress ที่ผ่านโจทย์เดิมยังคงอยู่ตามคำขอ จึงอาจทำให้ผู้เล่นเดิมถูกนับว่าผ่านโจทย์ใหม่แล้ว

## ผลตรวจสอบ / สิ่งที่เหลือ

- ตรวจข้อมูลผ่าน `mini_game_exercises` view แล้วตรงกับ CSV ทั้ง 7 IDs
- เฉลยในข้อมูลใหม่ทั้ง 7 ข้อผ่าน `miniGameGrader` (1/1 test ต่อข้อ)
- ยืนยันว่า dialogues/choices/progress/submissions ที่มีอยู่ยังอยู่ครบตามจำนวนเดิม
- `npm run test:problems` และ `npm run test:bilingual` ใช้ direct PGHOST localhost และยืนยันตัวตนไม่ผ่านใน environment นี้; ไม่ได้แก้ข้อมูลพิเศษให้สคริปต์ทดสอบ
- `server/seed-content.sql` ยังเป็น generated snapshot เก่า; การ regenerate ต้องทำจากฐานข้อมูลต้นทางด้วย `node scripts/dump-schema.js`
