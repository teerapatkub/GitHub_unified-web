# แก้ Spacebar ข้ามข้อความบทสนทนา

**วันที่และเวลา:** 2026-10-28 03:17 น.

## สรุปการเปลี่ยนแปลง

- `client/src/pages/MiNi_Game.jsx` — เก็บ interval ของการพิมพ์ข้อความใน ref และยกเลิก interval พร้อมหยุดเสียงเมื่อกด Spacebar เพื่อแสดงข้อความทั้งหมด
- `docs/handoff-to-person-1.md` — แจ้ง handoff เนื่องจาก `MiNi_Game.jsx` เป็นไฟล์ในขอบเขตของ Person 1

## เหตุผล

เดิม Spacebar ตั้งข้อความที่แสดงให้ครบ แต่ interval ที่ทำงานอยู่ยังคงอัปเดตข้อความบางส่วนต่อ จึงดูเหมือนข้อความยังค่อยๆ แสดงหลังจากกดข้าม

## ผลกระทบต่อส่วนอื่น

จำกัดอยู่ที่การข้ามข้อความและเสียงประกอบของบทสนทนา ไม่เปลี่ยนลำดับบทสนทนา ตัวเลือก หรือระบบส่งคำตอบ

## ผลตรวจสอบ / สิ่งที่เหลือ

- ESLint เฉพาะไฟล์ผ่านโดยไม่มี error; มี warning เรื่อง dependency ของ `useEffect` เดิมที่บรรทัด 732
- `npm run build` ผ่าน
- ยังไม่ได้ทดสอบการกด Spacebar บนหน้าเกมจริงใน browser
