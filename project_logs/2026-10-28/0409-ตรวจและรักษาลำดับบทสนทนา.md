# ตรวจและรักษาลำดับบทสนทนา

**วันที่และเวลา:** 2026-10-28 04:09 น.

## สรุปการเปลี่ยนแปลง

- `client/src/pages/MiNi_Game.jsx` — ปรับ `getVisibleDialogues()` ให้กรองตาม branch และ phase โดยรักษาลำดับแถวต้นฉบับที่ API เรียงตาม `dialogue_order`
- หลัง DONE สำเร็จ จะไม่พิมพ์บทสนทนาที่มี choices ซ้ำ แต่แสดงข้อความครบและ choices ต่อทันที
- `docs/handoff-to-person-1.md` — บันทึกผลตรวจลำดับข้อมูลจริงและการปรับโค้ด

## เหตุผล

การรวม `pre_submit` และ `post_submit` ด้วยการต่อ array อาจสลับลำดับเมื่อ phase สองแบบคละกัน แม้ข้อมูล local ที่ตรวจปัจจุบันจะมีแต่ `pre_submit`

## ผลกระทบที่อาจมีต่อส่วนอื่น

การเลือกบทสนทนาตาม phase และ branch คงเดิม แต่เมื่อแสดงหลาย phase พร้อมกันจะรักษา `dialogue_order` แทนการแยกกลุ่ม; หลังผลตรวจผ่านจะไม่เริ่มพิมพ์บทสนทนาที่มี choices ซ้ำ

## ผลตรวจสอบ / สิ่งที่เหลือ

- อ่านข้อมูลฐานข้อมูล local แบบ read-only แล้วยืนยันลำดับด่าน, dialogue และ choice routes ของบท 1
- build ผ่าน; ESLint ไม่มี error และมี warning dependency ของ `useEffect` เดิม
- ยังไม่ได้ทดสอบเส้นทางนี้ใน browser จริง
