# คีย์ตัวตรวจโค้ดชุดใหม่ และยืนยันว่าคีย์ที่รั่วถูกเพิกถอนแล้ว

**วันที่:** 2026-08-25 เวลา 15:00
**ผู้ทำ:** Person 3

---

## 1. สิ่งที่แก้

แก้เฉพาะ `server/.env` (ไม่อยู่ใน git) — **ไม่มีการแก้โค้ด**

`NVIDIA_CODE_JUDGE_API_KEY` เปลี่ยนเป็นคีย์ชุดใหม่ที่ผู้ใช้ส่งมา
`NVIDIA_CODE_JUDGE_MODEL` คงเดิมที่ `nvidia/nemotron-3-super-120b-a12b`

คีย์ก่อนหน้าถูกผู้ใช้ลบไปตอนเก็บกวาดคีย์ ทำให้การตรวจคุณภาพโค้ดตกไปใช้ตัวคำนวณ
ในเครื่องอยู่ระยะหนึ่ง (ระบบไม่พัง แต่คะแนนหยาบลง) ตอนนี้กลับมาใช้ AI แล้ว

## 2. ทดสอบ (ยิงผ่าน server จริง)

| สิ่งที่ทดสอบ | ผล |
|---|---|
| `POST /api/arcade/rooms/:id/judge-round` โค้ดดี | HTTP 200 · 1,798 ms · score 85 · `source: ai` |
| `POST /api/arcade/rooms/:id/judge-round` โค้ดเปล่า (`pass`) | HTTP 200 · 739 ms · score 5 · `source: ai` |
| `POST /api/competitive/challenges/4/submit` คำตอบถูก | HTTP 200 · 5,037 ms · `aiReviewed: true` · `aiVerdict: approved` · score 100 |

ทั้งสองที่ใช้คีย์และโมเดลชุดเดียวกัน แยกจากแชทบอทตามกฎใน `CLAUDE.md`

การเผยแพร่ repo สาธารณะจึงไม่เปิดเผยความลับที่ยังมีผล
