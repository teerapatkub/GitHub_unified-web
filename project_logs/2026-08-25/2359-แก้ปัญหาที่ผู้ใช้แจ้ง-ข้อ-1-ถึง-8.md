## 1. โจทย์โหมดแข่งที่หมดอายุต้องหายไป

`expires_at` มีอยู่ในตารางมาตลอดแต่**ไม่มีโค้ดตรงไหนบังคับใช้เลย** โจทย์ทั้ง 13 ข้อ
ในสนามแข่งเลยวันหมดอายุไปแล้วทั้งหมด (เก่าสุดตั้งแต่ 17 ก.ค.) แต่ยังขึ้นให้เห็น
ยังกดรับได้ และยังจ่ายรางวัลได้

แก้ที่ `GET /api/competitive/challenges` ให้กรอง `expires_at IS NULL OR expires_at > CURRENT_TIMESTAMP`
และ**ตรวจซ้ำที่ `POST /:id/accept`** ด้วย เพราะเบราว์เซอร์ที่ยังถือรายการเก่าค้างไว้
จะกดรับโจทย์ที่หายไปแล้วได้ แล้วถูกให้คะแนนบนโจทย์นั้น — คืน HTTP 410 พร้อมข้อความไทย

**แถวยังอยู่ในฐานข้อมูลครบ** ไม่มีการลบ ตามที่ผู้ใช้สั่ง — ตรงกับ `CONTEXT.md` ที่แยก
*โจทย์* ออกจาก *ทะเบียนโหมด* อยู่แล้ว

ยืนยันบนหน้าจอ: รายการลดจาก **13 เหลือ 2** ข้อ

## 2. โจทย์ที่เป็น "ภาษาแปลกๆ"

ไม่ใช่ข้อมูลในฐานข้อมูล และไม่ใช่ปัญหาของเบราว์เซอร์ — **เป็นสตริงในซอร์สโค้ดเอง**
`CompetitiveArena.jsx` มีข้อความไทย 33 จุดที่ถูกบันทึกด้วยการเดารหัสอักขระผิด
กลายเป็นอักษรไทยที่อ่านไม่ออก (UTF-8 ที่ถูกอ่านกลับเป็น CP874) และ
`ExercisePage.jsx` อีก 1 จุด รวม **34 จุด** แก้กลับเป็นข้อความจริงทั้งหมด

พอข้อ 1 ซ่อนโจทย์หมดอายุ เหลือแค่โจทย์ทดสอบระบบสองข้อ ซึ่งชื่อและคำอธิบายมาจาก
สตริงที่พังพอดี ผู้ใช้จึงเห็นเป็นภาษาประหลาดเต็มหน้า

**เพิ่ม `npm run check:text`** — สแกนทั้ง repo แล้วลองถอดรหัสย้อนกลับ: ข้อความไทยจริง
ถอดไม่ผ่าน ส่วนข้อความที่พังแบบนี้ถอดผ่านและได้ภาษาไทยที่อ่านออก จึงรายงานพร้อมบอกว่า
"ควรเป็น" อะไร ทดสอบแล้วว่าจับของจริงได้ (เอาไฟล์เก่ากลับมา แล้วเทสตก 33 จุด)

**แก้คำอธิบายที่ทำให้เข้าใจผิดด้วย** โจทย์ทดสอบระบบเขียนว่า "แม้ส่งไฟล์เปล่าไร้โค้ด
ก็สามารถผ่านและได้รับรางวัล" ซึ่งไม่จริงแล้ว — ตัวตรวจรัน Python จริงและให้ 0 คะแนน
ผู้เริ่มต้นที่เชื่อประโยคนี้จะส่งไฟล์เปล่าแล้วงงว่าทำไมได้ 0

## 3. บัคเวลาใน Arcade

เป็นบั๊กเดิมที่แก้ไปแล้วเมื่อคืนนี้ (`db.js` แปลง JS `Date` เป็น UTC ก่อนเขียน)
ภาพที่ผู้ใช้ส่งมาถ่ายก่อนแก้ ตอนนี้ยืนยันสองทาง: `npm run check:time` **6/6**
และเล่นจริงบนหน้าจอ นาฬิกาเดิน **58s แล้ว 50s** ตามปกติ

## 4. หลอด progress ของบอทวนกลับไป 0

`botAI.js` เพิ่ม progress ครั้งละ 15–39% ต่อจังหวะพิมพ์ แล้วพอถึง 100 ก็ตั้งกลับเป็น 0
เพื่อจะนับ "แก้โจทย์ได้อีกข้อ" — ในรอบ 60 วินาทีจึงวนประมาณ **13 รอบ** หลอดที่วนแบบนี้
ไม่ได้บอกอะไรผู้เล่นเลย ทั้งที่มันเป็นสัญญาณเดียวที่บอกว่าคู่แข่งใกล้เสร็จแค่ไหน

แก้เป็น: สุ่มจำนวนจังหวะที่ต้องใช้ต่อรอบ (22–34 จังหวะ) แล้วเดินหน้าอย่างเดียว
หยุดที่ 100 และคะแนนโบนัสในใจของบอทให้ครั้งเดียวต่อรอบ ผลคือบอทเร็วสุด (1200ms)
ทำเสร็จราว 26–41 วินาที ส่วนบอทช้าสุด (2200ms) มักทำไม่ทันในรอบ — เรียงลำดับตามที่
โปรไฟล์บอทอธิบายไว้จริงๆ

**เพิ่ม `npm run test:bot-progress`** (18 ข้อ) รัน `BotAIEngine` ตัวจริงทีละ tick
แล้วดู**ประวัติทั้งรอบ** ไม่ใช่ค่าสุดท้าย — หลอดที่วนกลับ ถ้าดูจากค่าสุดท้ายอย่างเดียว
ไม่มีทางจับได้ ทดสอบแล้วว่าโค้ดเก่าตก 9 ข้อ

โหลดโมดูลจากซอร์สโดยแทน JSON import ให้ เพราะ Node import ไฟล์ `.json` แบบที่ Vite ทำไม่ได้
— ทางเลือกอื่นคือก๊อปปี้ตรรกะมาไว้ในเทส ซึ่งจะผ่านต่อไปเรื่อยๆ แม้ไฟล์จริงพัง

ยืนยันบนหน้าจอ: 96% แล้ว 100% แล้ว**ค้างที่ 100%** ตลอดรอบ และรีเซ็ตเป็น 0% เมื่อขึ้นรอบใหม่

## 5. ลบเลขข้อออกจากโจทย์ทั้งหมด

มี 80 จุด (โจทย์ Arcade 40 ข้อ คูณ `title_th` กับ `title_en`) เช่น "1. เลขฟีโบนัชชี"
เลขนี้มาจากสมัยที่คลังโจทย์เป็นลิสต์เรียงลำดับ แต่ตอนนี้แต่ละรอบ**สุ่ม**จากคลังทั้งหมด
รอบ 1 อาจได้ข้อ "7." รอบ 2 ได้ "3." ซึ่งอ่านแล้วเหมือนเกมข้ามโจทย์ไป 6 ข้อ

แก้ทั้งใน `arcadeTaskSeed.js` และในฐานข้อมูล **และลำดับสำคัญ**: การ upsert ตอนบูต
จับคู่แถวด้วย `title_en` ถ้าแก้แค่ไฟล์ seed จะหาแถวเดิมไม่เจอแล้ว**แทรกโจทย์ซ้ำอีก 40 ข้อ**
migration ใน `db.js` จึงตัดเลขในฐานข้อมูลก่อน แล้วค่อย upsert (idempotent รันซ้ำได้)

`test:problems` จับได้ทันทีเพราะเทียบกับสำเนาก่อนรวม — เพิ่ม **กฎยกเว้นแบบมีเงื่อนไข**
(`DELIBERATE_RULES`) แทนการไล่ยกเว้นทีละ 80 บรรทัด กฎบอกว่า "ต่างกันได้เฉพาะเลขข้อที่ถูกตัด"
ชื่อที่เปลี่ยนด้วยเหตุอื่นยังถูกรายงานอยู่ และกฎที่ไม่ตรงกับความต่างจริงแล้วจะทำให้เทสตก
เหมือนรายการยกเว้นเดิม

ยืนยัน: ชื่อโจทย์ที่ยังมีเลข **0 จุด** · ทะเบียน arcade ยัง **40** · โจทย์รวมยัง **192**

## 6. error ใน console

| ที่เห็นในภาพ | สาเหตุจริง | ทำอะไร |
|---|---|---|
| `[GSI_LOGGER] ... FedCM becomes mandatory` | SDK ของ Google เตือนทุกครั้งที่โหลด จนกว่าเว็บจะเปิด FedCM | เปิด `use_fedcm_for_prompt: true` และเลิกใช้ `isNotDisplayed()`/`isSkippedMoment()` ที่ FedCM ยกเลิกไปแล้ว |
| `accounts.google.com/...` **403** | origin `http://localhost:5174` ยังไม่ได้อยู่ใน Authorized JavaScript origins ของ Google Cloud Console | **แก้ในโค้ดไม่ได้** ต้องเพิ่ม origin ในหน้า Credentials ของโปรเจค Google เอง |
| `ExercisePage.jsx` **500** และ `[vite] Failed to reload` | vite ทรานส์ฟอร์มไฟล์ระหว่างที่ยังบันทึกไม่เสร็จ | ตรวจแล้วไม่ใช่บั๊กค้าง: ขอไฟล์ตรงๆ ได้ **200** และ `npm run build` ผ่าน |

ตรวจ console บนหน้าจอจริงหลังแก้: หน้า Arcade และหน้า `/debug` **ไม่มี error เลย**

## 7. UI Arcade — พื้นที่มากขึ้น และย่อ/ขยายได้

- การ์ดโจทย์และเทอร์มินัลกดย่อได้ทั้งคู่ (ปุ่มลูกศรที่หัวแต่ละส่วน)
  ย่อแล้วยังเห็นชื่อโจทย์ นาฬิกา และเงินอยู่ ส่วนเทอร์มินัลยังเหลือแถบหัวไว้ให้รู้ว่าผลจะออกตรงไหน
- **จำค่าไว้ใน localStorage** เพราะหน้านี้ถูก unmount ทุกช่วงพักซื้อของ ถ้าไม่จำ
  ผู้เล่นที่ย่อการ์ดไว้จะโดนกางคืน 3 ครั้งต่อแมตช์
- ลด padding รอบนอก 24 เหลือ 16px, ย่อคอลัมน์ขวา 420 เหลือ 360px,
  ลดความสูงแถบปุ่ม 64 เหลือ 56px — พื้นที่ที่ได้กลับมาทั้งหมดตกเป็นของ editor

## 8. แถบเลื่อนระหว่าง editor กับรายชื่อผู้เล่น

คอลัมน์ซ้ายเป็น `overflow-y-auto` แถบเลื่อนจึงวาดอยู่ในช่องว่างระหว่างสองคอลัมน์พอดี
และอ่านดูเหมือนเส้นแบ่งกลางจอ เพิ่มคลาส `.no-scrollbar` ใน `index.css`
(ซ่อนเฉพาะตัวแถบ ยังเลื่อนด้วยล้อ/แทร็กแพด/คีย์บอร์ดได้ตามปกติ) ใช้กับคอลัมน์ซ้าย
รายชื่อคู่แข่ง และกล่องนอกสุด

ยืนยันบนหน้าจอ: `offsetWidth - clientWidth = 0` ทุกกล่อง และไม่มีเส้นในภาพอีก

**เรื่องรอง**: เปอร์เซ็นต์ของบอทแสดงเป็นทศนิยมยาวมาก เพราะไม่เคยปัดเศษ
(ของเดิมบวกทีละจำนวนเต็มเลยไม่เห็น) ปัดด้วย `Math.round` แล้ว
