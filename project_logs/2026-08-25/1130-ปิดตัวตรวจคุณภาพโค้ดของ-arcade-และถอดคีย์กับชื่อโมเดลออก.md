# ปิดตัวตรวจคุณภาพโค้ดของ Arcade — ถอดคีย์และชื่อโมเดลออก

**วันที่:** 2026-08-25 เวลา 11:30
**ผู้ทำ:** Person 3
**เหตุผล:** ผู้ใช้แจ้งความกังวลด้านความปลอดภัยเกี่ยวกับ API และโมเดล
`nvidia/nemotron-3.5-lightning-30b-a3b` ที่ใช้ตรวจคุณภาพโค้ดใน Arcade และขอให้ถอดออก
โดยเว้นคอมเมนต์ไว้แทน

---

## 1. สิ่งที่แก้

| ไฟล์ | ทำอะไร |
|---|---|
| `server/.env` | ลบค่า `NVIDIA_CODE_JUDGE_API_KEY` เหลือเป็นช่องว่างพร้อมคอมเมนต์ และเพิ่ม `NVIDIA_CODE_JUDGE_MODEL=` ว่างไว้ |
| `server/server.js` | ย้ายชื่อโมเดลออกจากโค้ดมาอ่านจาก `.env` และปิดการเรียก AI เมื่อคีย์หรือชื่อโมเดลว่าง |
| `server/.env.example` | เพิ่มสองตัวแปรนี้เป็นช่องว่างพร้อมคำอธิบาย |
| `.gitignore` | กันไฟล์สำรอง `.env.backup*` ไม่ให้เข้า git |

**ชื่อโมเดลเคยถูกเขียนตายไว้ในโค้ด** ซึ่งขัดกับกฎใน `CLAUDE.md` ที่บังคับให้ชื่อโมเดลอ่านจาก
`.env` เสมอ ผลคือปิดโมเดลนี้ไม่ได้เลยถ้าไม่แก้โค้ด ตอนนี้ทั้งคีย์และชื่อโมเดลอยู่ใน `.env`
และ **ถ้าอันใดอันหนึ่งว่าง ระบบจะไม่ติดต่อ NVIDIA เลย**

## 2. ผลต่อระบบ

Arcade **ยังทำงานครบทุกอย่าง** เพราะเส้นทางสำรองมีอยู่แล้วตั้งแต่แรก — `judgeCodeQuality()`
ถูกออกแบบให้คืนค่าเสมอและไม่เคยโยน error เพื่อไม่ให้รอบค้าง เมื่อไม่มีคีย์มันจะใช้
`heuristicCodeQualityScore()` ซึ่งคำนวณในเครื่องจากความยาวบรรทัด การตั้งชื่อ และการมีคอมเมนต์

**ผลข้างเคียงที่เป็นประโยชน์ต่อความเป็นส่วนตัว**: ตอนนี้โค้ดที่ผู้เล่นเขียนไม่ถูกส่งออกนอกเครื่อง
อีกต่อไปในเส้นทางนี้ ก่อนหน้านี้โค้ดของผู้เล่นทุกคนถูกส่งไปยัง NVIDIA ทุกครั้งที่จบรอบ

**สิ่งที่เปลี่ยนไปในเชิงเกม**: คะแนนคุณภาพโค้ดจะหยาบขึ้น เพราะตัวคำนวณในเครื่องดูรูปแบบ
ของโค้ด ไม่ได้เข้าใจความหมาย คะแนนรอบยังคิดจากสามส่วนเหมือนเดิม (ความถูกต้อง + คุณภาพ + เวลา)

เป็นอาการเดิมที่บันทึกไว้แล้วว่า timeout 6 วินาทีของตัวตรวจตึงเกินไปเมื่อเครื่องมีภาระหนัก
ไม่เกี่ยวกับการแก้ครั้งนี้ และอยู่ในสเปกก้อนที่ 1 แล้ว

## 4. สิ่งที่ยังต้องทำ

- **การลบคีย์ออกจาก `.env` ไม่ได้เพิกถอนคีย์** ตัวคีย์ยังใช้งานได้อยู่จนกว่าจะเข้าไปเพิกถอน
  ที่หน้าเว็บของ NVIDIA — ต้องทำ เพราะคีย์นี้เคยอยู่ในไฟล์ที่ส่งต่อกันในทีม
- **ไฟล์สำรอง `server/.env.backup-before-key-removal` ยังมีคีย์เดิมแบบข้อความธรรมดา**
  กัน git ไว้แล้วแต่ยังอยู่บนดิสก์ ควรลบทิ้งหลังเพิกถอนคีย์เรียบร้อย
- คีย์ของแชทบอท (`NVIDIA_API_KEY`) **ยังไม่ถูกแตะ** ตามที่ผู้ใช้ระบุเฉพาะตัวตรวจโค้ด
  ถ้าต้องการปิดด้วยให้แจ้ง — Lumi และตัวสร้างโจทย์ด้วย AI จะเปลี่ยนไปใช้เนื้อหาสำรองแทน
- `server/.env.example` มี `NVIDIA_API_KEY` ซ้ำสองบรรทัดและ `NVIDIA_MODEL=moonshotai/kimi-k2.5`
  ที่ไม่มีโค้ดส่วนใดอ่าน ตกค้างจากตอนรวมโปรเจคของ Person 2 — ยังไม่แก้ในรอบนี้
