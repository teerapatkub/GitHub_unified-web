# เปลี่ยนโมเดลแชทบอทเป็น nemotron-3-ultra และ push ขึ้น GitHub

และสั่งให้ push งานขึ้น GitHub

## 1. สิ่งที่แก้

แก้เฉพาะ `server/.env` ซึ่งไม่ได้อยู่ใน git — **ไม่มีการแก้โค้ดเลย** เพราะชื่อโมเดลกับคีย์
ถูกย้ายออกมาอยู่ใน `.env` ทั้งหมดแล้วตั้งแต่รอบก่อน

| ค่า | เดิม | ใหม่ |
|---|---|---|
| `NVIDIA_API_KEY` | คีย์เดิม | คีย์ใหม่ที่ผู้ใช้ส่งมา |
| `NVIDIA_AI_MODEL` | `moonshotai/kimi-k3` | `nvidia/nemotron-3-ultra-550b-a55b` |
| `NVIDIA_AI_TIMEOUT_MS` | 90000 | **120000** (เหตุผลด้านล่าง) |

ตัวตรวจโค้ด (`nvidia/nemotron-3-super-120b-a12b`) ไม่ถูกแตะ ยังแยกคีย์และแยกโมเดล
จากแชทบอทตามกฎใน `CLAUDE.md`

## 2. โมเดลใหม่ช้ากว่าเดิมมาก — วัดจริงแล้ว

| การทดสอบ | เวลา |
|---|---|
| ถามคำถามภาษาไทยสั้นๆ (เรียกโมเดลตรง) | **79.9 วินาที** |
| ขอ JSON สำหรับสร้างโจทย์ | **51.4 วินาที** |
| วัดซ้ำด้วย `thinking:false` | 52.4 วินาที |
| วัดซ้ำด้วย `enable_thinking:false` ตามตัวอย่างที่ผู้ใช้ส่ง | 87.6 วินาที |
| **ยิงผ่าน `POST /api/ai/chat` จริง** | **54.0 วินาที** (HTTP 200 คำตอบถูกต้อง) |

**ไม่ใช่เพราะโหมดคิดเยอะ** — ตรวจแล้วว่า `reasoning_content` ว่างเปล่าทั้งสองแบบ
คือปิดโหมดคิดได้จริงทั้งคู่ ความช้ามาจากตัวโมเดลเอง (550B)

เทียบกับของเดิม: kimi-k3 เคยวัดได้ 1.4 / 7.4 / 14.1 วินาที และตัวตรวจโค้ด
nemotron-3-super-120b ตอบภาษาไทยพร้อม JSON ใน **1.4 วินาที**

**จึงต้องขยาย timeout จาก 90 เป็น 120 วินาที** เพราะค่าที่วัดได้สูงสุด 87.6 วินาที
เฉียดของเดิมเกินไป ถ้าเกินแล้วผู้เรียนจะได้ข้อความสำรองแทนคำตอบจริง

**ผลต่อผู้ใช้**: ผู้เรียนที่ถาม Lumi จะรอราวหนึ่งนาที ซึ่งขัดกับกลุ่มเป้าหมายที่เป็น
ผู้เริ่มต้น — แจ้งผู้ใช้แล้วพร้อมทางเลือก
