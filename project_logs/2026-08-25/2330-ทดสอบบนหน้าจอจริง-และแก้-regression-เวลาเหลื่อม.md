## 2. regression ที่การทดสอบหน้าจอจับได้ (ชุดทดสอบทั้งหมดเขียวอยู่)

**อาการบนหน้าจอ**: นาฬิการอบของ Arcade แสดง **25,197 วินาที** แทนที่จะเป็น ~60

**สาเหตุ**: การแก้ใบ 2 ทำให้การ *อ่าน* คอลัมน์ `timestamp` เป็น UTC ทั้งหมด แต่ยังมีโค้ดที่ *เขียน*
ด้วย JS `Date` อยู่ 4 จุด (`phase_deadline`) — pg จะ serialize `Date` ด้วย offset ท้องถิ่น
แล้ว PostgreSQL ตัด offset ทิ้งตอน cast ลง `timestamp` ตัวเลขที่เก็บจึงเป็นเวลาท้องถิ่น
ขณะที่ `current_timestamp` เก็บเป็น UTC — **สองแบบในคอลัมน์ชนิดเดียวกัน**

ก่อนแก้ใบ 2 ทั้งคู่ถูกอ่านเป็นเวลาท้องถิ่น: ค่าจาก `current_timestamp` ผิด 7 ชั่วโมง (บั๊กโหมดแข่ง)
ส่วนค่าจาก JS `Date` ถูกพอดี หลังแก้จึงกลับด้าน

**ทำไมเทสไม่จับ**: `server-scoring-test` บังคับปิดรอบด้วย `CURRENT_TIMESTAMP` จึงไม่เคยเดินผ่าน
เส้นทางที่เขียนด้วย JS `Date` เลย

**แก้ที่ `db.js`**: `normalizeParams` แปลง `Date` เป็น ISO-8601 UTC ก่อนส่งเข้า query
แก้ที่ชั้นเดียวแทนการไล่แก้ 4 จุด เพราะโค้ดที่เขียนทีหลังจะได้ถูกต้องโดยไม่ต้องรู้เรื่องนี้
และถูกต้องกับคอลัมน์ `timestamptz` ด้วย

**เพิ่มเทสดัก**: `check:time` เพิ่มกรณี "เขียนด้วย JS Date แล้วอ่านกลับได้เวลาเดิม"
ผ่าน `db.js` (ชั้นที่โค้ดจริงใช้) — ก่อนแก้ตก แสดง 25200 วินาที ตอนนี้ **6/6**

ยืนยันบนหน้าจอ: นาฬิกากลับมาแสดง **19s** ตามจริง

### Arcade — ก้อน 2

เล่นแมตช์จริงผ่านเบราว์เซอร์ (สร้างห้อง เพิ่มบอท เริ่มแมตช์) แล้วดูหน้าสรุปผล:

```
รอบ 1  ✅ 2/5   📖 10/100  ⏱ 53s  → 55 pt
รอบ 2  ✅ 0/4   📖 10/100  ⏱ 53s  → 10 pt
```

**ทุกตัวเลขนี้ server คำนวณเอง** — จำนวนเทสที่ผ่านมาจากการรันโค้ดจริง คุณภาพจาก AI
เวลาจากนาฬิกาของ server และคะแนนรวมตรงกับสูตรเป๊ะ (2/5 × 100 + 10 + 0.4 × 7/60 × 100 ≈ 55)

ระบบส่งอัตโนมัติทำงานด้วย — ผมไม่ได้กดส่งเลยทั้งสองรอบ

**ปุ่ม "ทดสอบโค้ด"** (ใบ 14): ใส่ `print("HELLO-TRIAL")` และ `print(2*21)` แล้วกด
ได้ผลลัพธ์จริง `HELLO-TRIAL` / `42` — ไม่มีคำว่า PASS ปลอมอีกแล้ว

## 4. บั๊กเก่าที่การทดสอบเปิดโปง

**แชท Lumi ในหน้าแบบฝึกหัดพังมาตลอด** — ส่ง `{message, code, level, ...}` แต่
`POST /api/ai/chat` อ่าน `{messages}` เป็น array แบบ OpenAI ทุกคำถามจากหน้านี้จึงได้ 500
และผู้เรียนเห็นข้อความสำรอง "ระบบ AI ตอบกลับไม่ได้ชั่วคราว" เสมอ

แก้เป็นส่ง `messages` พร้อมบริบทโจทย์ใน system message และประวัติแชท 6 ข้อความล่าสุด
ยืนยันแล้วว่าได้ 200 และคำตอบมีคุณภาพ

## 5. ความผิดพลาดของผมระหว่างทดสอบ

- ใช้ `form_input` กรอกชื่อห้อง แล้วสรุปว่าปุ่มสร้างห้องพัง — ที่จริง `form_input`
  ตั้งค่า DOM โดยไม่ trigger React การพิมพ์จริงใช้งานได้ปกติ **ไม่ใช่บั๊กของเว็บ**
- สรุปว่าปุ่มลองรันพัง เพราะกดทันทีหลังตั้งค่า Monaco โดยไม่รอ React อัปเดต state
  จึงรันโค้ดตั้งต้นที่ไม่พิมพ์อะไร เว้นจังหวะแล้วทำงานถูกต้อง **ไม่ใช่บั๊กของเว็บ**

ทั้งสองครั้งผมเกือบแก้โค้ดที่ไม่ได้เสีย
