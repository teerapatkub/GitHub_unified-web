# 2026-11-17 10:00 — เพดานเลเวล 100, XP ต่อเลเวลเพิ่มขึ้นเรื่อยๆ และแสดงเหรียญไม่เกิน 99,999 (ข้อ 11 ใน `สิ่งที่ต้องแก้ไข.md`)

## ที่ผู้ใช้ตัดสิน
- **XP ต่อเลเวลเพิ่มทีละ 60:** เลเวล L → L+1 ใช้ `100 + 60 × (L − 1)` XP
  - ถึง Lv.10 (ปลดล็อกโหมดเกม) = 3,060 XP ใกล้กับ XP จากแบบฝึกหัดบทเรียนทั้งหมด (~3,400)
  - ถึง Lv.100 = 299,880 XP
- **ผู้เล่นเดิมคงเลเวลเดิม** และแปลง XP ให้เข้ากับสูตรใหม่
- **เพดานเหรียญเป็นแค่การแสดงผล:** เหรียญจริงยังเพิ่มและใช้ได้ตามปกติ แต่ทุกจุดที่แสดงยอดเงินจะไม่เกิน 99,999

## ปัญหาเดิม: สูตรเลเวล 3 แบบที่ไม่ตรงกัน
- **รางวัลบทเรียน/มินิเกม (`applyXpRewardToUser`):** ขึ้นเลเวลแล้วรีเซ็ต XP เป็น 0 และต้องมี XP ≥ เลเวล × 1,000 ถึงจะขึ้นอีก
  - จาก Lv.3 ไป Lv.10 ใช้ประมาณ 42,000 XP
- **รางวัล Debug Lab / Challenge:** เก็บ XP สะสม 1,000 ต่อเลเวล
- **แถบในหน้าโปรไฟล์:** `xp % 1000 / 1000`
- **หน้าบทเรียน:** คำนวณเองฝั่ง client ด้วยเส้นโค้ง 120 × เลเวล
- **ผล:** แถบที่ผู้เล่นเห็นแทบไม่เคยตรงกับเลเวลจริง และไม่มีเพดานเลเวล

## สิ่งที่แก้
- **`server/levels.js` (ใหม่):** ที่เดียวที่แปลง XP เป็นเลเวล
  - `users.xp` คือ XP สะสมทั้งหมด ไม่รีเซ็ต
  - `addXp` บวก XP แล้วคำนวณเลเวลใหม่ เลเวลไม่ลดและไม่เกิน 100
  - XP หลัง Lv.100 ยังสะสมต่อ และแถบแสดง MAX
  - **เลเวลที่ได้โดยไม่ใช้ XP (placement ตอนสมัคร, สอบเลื่อนระดับ):** นับต่อจาก XP เริ่มต้นของเลเวลนั้น (`effectiveXp`) แถบจึงไม่ติดลบ
- **`server/server.js`:**
  - รางวัลทั้งสองทาง (`applyXpRewardToUser` และ submit ของ Debug Lab/Challenge) ใช้ `levels.addXp`
  - `/api/profile/:id` ส่ง `progression` จาก `levels.progressFor` พร้อม `max_level`
  - `/api/user/profile/:id` ส่ง `progression` ให้หน้าบทเรียนด้วย (เดิมไม่ส่ง หน้าบทเรียนจึงคำนวณเอง)
- **migration `202611170006 level_curve_total_xp` (`server/migrate-level-curve.js`):** แปลงผู้เล่นเดิมด้วย SQL คำสั่งเดียว
  - **เลเวลเกิน 100:** ลดเหลือ 100
  - **XP ใหม่:** XP เริ่มต้นของเลเวลนั้น + XP ที่มีอยู่ (ไม่เกิน XP ที่ต้องใช้ − 1) จึงไม่มีใครเลเวลขึ้นหรือลงจากการแปลง
  - **ที่ Lv.100:** XP ส่วนเกินเก็บไว้ทั้งหมด
  - **เลเวล 0 (ยังไม่ทำ placement):** ไม่แตะ
  - checksum มีแค่ไฟล์ migration ไม่รวม `levels.js` ถ้าแก้สูตรภายหลัง ฐานที่ migrate แล้วยังบูตได้
- **client:**
  - **หน้าบทเรียน:** ลบเส้นโค้ง 120 × เลเวลออก ใช้ `progression` จาก server อย่างเดียว ที่ Lv.100 แสดง MAX
  - **หน้าโปรไฟล์:** ที่ Lv.100 แสดง MAX และตัวเลข XP มีตัวคั่นหลักพัน
  - **`client/src/utils/coins.js` (ใหม่):** `displayCoins` แสดงยอดไม่เกิน 99,999 ใช้ที่ navbar, หน้าโปรไฟล์ และ leaderboard (กระดานเหรียญและบรรทัดรายละเอียด)
    - ลำดับใน leaderboard ยังเรียงตามยอดจริง
    - ราคาสินค้าและรางวัลไม่ได้ผ่านฟังก์ชันนี้
