# 2026-11-17 15:20 — ปรับ UI ให้ผู้เริ่มต้นเข้าใจง่าย รอบที่ 1 (ทิศทาง A "ขั้นต่อไปมาก่อน")

ผู้ใช้สั่งผ่าน /gridgeist ให้ปรับทั้งเว็บไม่ให้ดูเป็น AI slop และให้คนไม่มีพื้นฐานเข้าใจ UI ได้ เลือกทิศทาง A

## หลักที่ใช้ (design contract)
- คงสีและ token เดิม: น้ำเงิน Python = ปุ่มหลัก, เหลือง = รางวัล, สีประจำโหมด
- ป้ายเป็นภาษาไทยธรรมดา ไม่มีหัวข้อเล็กภาษาอังกฤษตัวพิมพ์ใหญ่ และไม่ใส่ letter-spacing กับข้อความไทย (ทำให้สระลอยแยก)
- แต่ละหน้าเริ่มด้วย "ขั้นต่อไป" หนึ่งอย่าง ปุ่มทึบปุ่มเดียว
- ปุ่มช่วยเหลือมีที่เดียว คือ "?" บน header และมันอธิบายหน้าที่เปิดอยู่

## สิ่งที่แก้
- **คู่มือหน้า (`WebTutorialModal.jsx`):** ใช้ spotlight ของ `GuidedTour` ชี้ปุ่มจริง แทนการ์ดกลางจอที่พิมพ์ selector ออกมา; เปิดจาก "?" บน header; ปุ่มลอยในห้าหน้าถูกลบ
- **หน้าบทเรียน (`LearningPage.jsx`):** แบนเนอร์คำขวัญสูง 280px ถูกแทนด้วยบล็อก "ทำต่อจากครั้งก่อน / ชื่อบท / หมวด · บทที่ x/y / ปุ่มเรียนต่อ" บนมือถือปุ่มเรียนต่ออยู่ในจอแรกแล้ว (เดิมต้องเลื่อน)
- **Debug Lab / Challenge (`CodingWorkspace.jsx`, `AiTaskPage.jsx`):** ป้ายไทยทั้งหมด, ผลตรวจบอก "ควรได้ / ได้จริง", ซ่อนบรรทัด "ถ้าป้อน:" เมื่อโจทย์ไม่มี input
- **แบบฝึกหัด (`ExercisePage.jsx`), Competitive (`CompetitiveArena.jsx`):** ป้ายไทย
- **แท็บย่อยบนมือถือ (`tubelight-navbar.jsx`):** มีคำกำกับ ไม่ใช่ไอคอนอย่างเดียว
- **เส้นสีฟ้าเขียวขวาบนทุกหน้า (`mode-entry.css`):** คือ scrollbar แนวตั้งของแถบแท็บโหมด (สูงเกิน 1px) แก้ด้วย `overflow-y: hidden`

## ผลทดสอบ (dev server จริง + Playwright, บัญชี ui_probe บน playtest DB)
- /learn ที่ 1366×800 และ 390×844: บล็อกขั้นต่อไปอยู่บนสุด, ไม่มีเส้นสีฟ้าเขียว (nav `overflow-y: hidden`)
- กด "?" บน /learn: spotlight ชี้ปุ่ม "เรียนต่อ" ในขั้นที่ 2
- /debug: กด "ตรวจคำตอบ" กับโค้ดที่มีบั๊ก ได้ "✗ ไม่ผ่านตัวอย่างที่ 1 / ควรได้ / ได้จริง"; กด "?" บน header แล้ว spotlight ชี้ปุ่มตรวจคำตอบ; มือถือ 390px ป้ายไทยครบ
- /online: หัวหน้าและเกณฑ์คะแนนเป็นไทย
- `npm run lint`: 0 error (warning 7 ตัวเดิม) · `npm run build`: ผ่าน

## ยังไม่ได้ทำ
- รอบถัดไปของทิศทาง A: หน้า Competitive (ลำดับกล่องโพสต์/อันดับ), ล็อบบี้ Arcade, แถบเมนูสามชั้น, หน้าบทเรียนและ MiNi Game (ปุ่ม RUN/DONE ยังเป็นอังกฤษเพราะคำใบ้ในเนื้อเรื่องอ้างชื่อนี้)

# รอบที่ 2 — Competitive และล็อบบี้ Arcade

## สิ่งที่แก้
- **Competitive (`CompetitiveArena.jsx`):**
  - เปลี่ยนกล่องโพสต์เป็นปุ่มรอง
  - อันดับรวมเป็นการ์ดเดียว
  - เพิ่มหัวข้อเหนือรายการโจทย์ "โจทย์ที่เปิดให้ทำ · n ข้อ"
  - เอาเกณฑ์คะแนนที่ซ้ำในทุกการ์ดออก
- **หัวของล็อบบี้ Arcade (`Arcade/widgets/PublicRoomBrowser.jsx`, `Arcade/translations.js`):**
  - **ข้อความ:** ตัดป้าย "PYARENA ARCADE" ออก หัวข้อใหม่คือ "แข่งเขียนโค้ดเอาตัวรอด สูงสุด 5 คน" พร้อมประโยคอธิบายกติกาหนึ่งบรรทัด
  - **ปุ่ม:** "สร้างห้อง" เป็นปุ่มหลัก ช่องรหัสห้องมีป้าย "มีรหัสห้องจากเพื่อน?" และปุ่ม "เข้าห้อง" เอาอีโมจิออกจากปุ่ม
  - **ห้องว่าง:** ปุ่มเป็นปุ่มรอง หน้าจึงไม่มีปุ่มแดงสองปุ่ม
- **scrollbar ที่ลอยกลางหน้า Arcade (`ArcadeBattleRoyale.jsx`):**
  - เดิมกล่องเลื่อนกว้าง max-w-7xl และจัดกลาง scrollbar จึงอยู่ในเนื้อหา
  - ตอนนี้กล่องเลื่อนกว้างเต็มจอ และจัดเนื้อหาให้อยู่กลางด้วย padding แทน
- ประวัติแมตช์ในล็อบบี้แสดง 3 รายการพร้อมลิงก์ไปหน้าประวัติทั้งหมดอยู่แล้ว (Spec 0005 #10) จึงไม่ได้แก้
