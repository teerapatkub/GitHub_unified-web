## สิ่งที่แก้
### หน้าเขียนโค้ด (ส่วนกลางใหม่ `client/src/components/workbench/`)
- ใช้หลักการจากภาพอ้างอิง ไม่ได้ลอกหน้าตา (ยังเป็นสีและฟอนต์ของ PyArena):
  - **ซ้าย:** หัวข้อ "โจทย์" พร้อมขั้นตอน 1-2-3 และรางวัล ตามด้วยหัวข้อ "ช่วยเหลือ"
  - **ขวา:** แท็บไฟล์และ editor แถบปุ่ม [⋯] … [ลองรัน] [ปุ่มหลัก] แล้วช่องผลลัพธ์
  - **footer:** ☰ รายการโจทย์ ชื่อข้อ "ข้อ 1/5" ป้ายผ่านแล้ว และปุ่มย้อนกลับ / ถัดไป ปุ่มถัดไปเป็นสีเหลืองเมื่อผ่านแล้ว
- **Lumi:** คอลัมน์ขวาที่ดัน editor ไปด้านข้าง บนมือถือทับเฉพาะส่วนโค้ด ปิดได้ด้วย X หรือ Esc
- **มือถือ:** สลับ "โจทย์ / เขียนโค้ด" แทนการซ้อน (เดิม editor บนมือถือถูกปุ่มและช่องผลลัพธ์บังจนมองไม่เห็น)
- `ExercisePage.jsx`, `CodingWorkspace.jsx` (Debug Lab, Challenge), `AiTaskPage.jsx`: ใช้ workbench
  - รายละเอียดอยู่ใน `docs/handoff-to-person-1.md`

### หน้าแข่ง Arcade (`pages/Arcade/widgets/BattleRoyaleGameplayView.jsx`, `translations.js`)
- **เดิมที่ 1366×768:** ปุ่มทดสอบ / ส่งคำตอบ ช่องผลลัพธ์ และช่องไอเทม อยู่ใต้จอทั้งหมด
- **คอลัมน์หลัก:**
  - แถบโจทย์กะทัดรัด: ชื่อ เวลา (เป็นสีแดงเมื่อเหลือไม่เกิน 10 วิ) และเงิน
  - คำอธิบายกับตัวอย่างเลื่อนในกล่องของตัวเอง สูงไม่เกิน 22% ของจอ
  - editor กินพื้นที่ที่เหลือ ปุ่มทดสอบ / ส่งอยู่ติดขอบล่างของ editor และช่องผลลัพธ์เล็กลง
- **คอลัมน์ข้าง:**
  - **"ไอเทมของคุณ" อยู่บนสุด:** การ์ดไอเทมมีชื่อและคำอธิบายสั้น พร้อมบรรทัดบอกสถานะ
    - รอบ 1 ใช้ไม่ได้ / แตะไอเทมเพื่อใช้ / แตะชื่อผู้เล่นเพื่อใช้ใส่เขา / ส่งแล้วรอบหน้าใช้ได้
    - กดไอเทมที่เลือกซ้ำเพื่อยกเลิก
  - **รายชื่อผู้เล่น:** แถวละบรรทัด คนที่โจมตีได้ขึ้น "⚡ ปล่อยการโจมตี" คนที่โดนอยู่แล้วเป็นสีเทา
- **ป้ายภาษาอังกฤษที่ฝังในโค้ดเปลี่ยนเป็นคีย์แปล:** "Active Problem", "Round Progress", "Firewall Active", "Python Interpreter online…" และ "(You)"
- ไม่ได้แตะตรรกะเกม ดีบัฟ บอท หรือ API
