## 1. ปิดช่องโหว่คะแนน

**ปัญหา**: `POST /submit-round` เชื่อคะแนนที่ client ส่งมาโดย clamp ไว้ที่ 999,999,999
ใครแก้ request ส่ง 999 ล้านก็ชนะทุกแมตช์ และคะแนนนั้นไหลเข้า `arcade_player_stats` เป็นสถิติถาวรด้วย
ส่วนฟิลด์ที่ใช้แสดงผลก็เก็บดิบๆ ทำให้ประวัติขึ้นได้ว่า "ผ่าน 7 จาก 5 ข้อ"

**แก้**: เพดานคะแนนย้ายไปอยู่ที่ `maxSubmittableRoundScore: 10000` ใน `shared/arcadeConfig.json`
(ตามที่ผู้ใช้เลือก) และ `pass_count` / `total_count` / `quality_score` / `time_used_seconds`
ถูกจำกัดให้อยู่ในช่วงที่เกมสร้างได้จริงทุกตัว

**บันทึกไว้ตรงๆ**: เพดานจริงตามสูตรคือ 600 (300 × 2 จาก scoreMultiplier) เพดาน 10000 กันค่าเพี้ยนมหาศาลได้
แต่**ไม่ได้กันคนที่ตั้งใจโกงส่ง 10000 แล้วขึ้นอันดับหนึ่ง** ผู้ใช้รับทราบ trade-off นี้แล้ว
และแก้ให้แคบลงทีหลังได้ด้วยการแก้ค่าเดียว

## 3. 🐛 เจอบั๊กใหญ่: resume แมตช์ไม่เคยทำงานเลย

ตอนทดสอบข้อ "กลับเข้าแมตช์หลังปิดเบราว์เซอร์" ครั้งแรกจริงๆ พบว่ามีบั๊กซ้อนกันสองชั้น

**ชั้นที่ 1 — ฟีเจอร์ลบข้อมูลของตัวเองทิ้งทุกครั้งที่เปิดหน้า**
effect ที่ *บันทึก* ห้อง กับ effect ที่ *กู้คืน* ห้อง ทำงานทั้งคู่ตอน mount และตัวบันทึกถูกประกาศไว้ก่อน
พอเปิดหน้าใหม่มันเห็น `currentRoom === null` แล้วเรียก `localStorage.removeItem()` —
ลบห้องที่บันทึกไว้ทิ้งก่อนที่ตัวกู้คืนจะได้อ่าน **เสี้ยววินาที** ทุกครั้ง
*พิสูจน์โดย*: เขียน key ลง localStorage เองแล้ว reload → กลับมาเป็น `null`
แก้โดยให้ลบได้ก็ต่อเมื่อ effect กู้คืนได้ทำงานไปแล้ว

**ชั้นที่ 2 — กู้คืนได้แล้ว แต่ได้โค้ดเริ่มต้นผิดข้อ**
การกู้ห้องต้อง resolve โจทย์ของรอบนั้น แต่คลังโจทย์ถูก fetch แยกและยังมาไม่ถึงในจังหวะนั้น
การ resolve จึงคืนค่าว่างแล้ว fallback ไปโจทย์ built-in — กลับเข้าแมตช์ระดับ medium แล้วเห็นหัวข้อ
"Valid Parentheses" อยู่เหนือ `def fib(n):` (ห้อง `ARC-CJVQ`)
แก้โดยให้การกู้คืนรอจนคลังโจทย์มาถึงก่อน (`tasksReady`)

## 6. การทดสอบรวมทั้งหมด

- `npm run test:arcade` — ผ่านทั้งชุด exit 0 (458 assertions + 7 + 7 + bot skill)
- **ทดสอบตัวทดสอบเอง**: ปลูกความผิด 4 แบบลงในสำเนาคลังโจทย์ (expected output ผิด, scaffold เป็นเฉลยเต็ม,
  hint ว่าง, ยกบรรทัดคำตอบใส่ hint) → จับได้ครบทั้ง 4 และ exit code 1
  *(ครั้งแรกจับได้ 3 จาก 4 แต่เป็นเพราะผมปลูกผิด — เลือกบรรทัดที่อยู่ใน scaffold อยู่แล้ว ไม่ใช่ตัวตรวจพลาด)*

  → เก็บจริงเป็น 10000, 5/5, quality 100, time 60
- ตัวตรวจ UI ตัดเนื้อหา — 0 จุด ทั้งที่ 1280×720 และ 375×812
- `npm run lint` ไม่มี error ใหม่ (เหลือ 7 อันเดิม), `npm run build` ผ่าน
- `arcade_rooms` เหลือ 0 แถวหลังทดสอบ
