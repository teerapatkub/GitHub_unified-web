# ทดสอบประสิทธิภาพ LLM ในเครื่องทุกด้าน

**ที่มา:** ผู้ใช้ขอให้ทดสอบประสิทธิภาพ LLM ทุกด้านและให้คะแนนแยกแต่ละส่วน

## สิ่งที่เพิ่ม

- **`server/scripts/llm-benchmark.js`:** สคริปต์ทดสอบ 12 ด้าน
  - ใช้ prompt เดียวกับ `server.js` และเรียก `arcade/code-judge.js` ตัวจริง
  - ตรวจโค้ดที่โมเดลเขียนด้วย `problemGrader`
- **`server/scripts/llm-benchmark-cases.js`:** ชุดคำถามและกรณีทดสอบ
- **`server/package.json`:** เพิ่ม `npm run bench:llm`
- **`docs/llm-benchmark/2026-10-27-report.md`:** รายงานคะแนน (รวม 79/100)
- **`docs/llm-benchmark/2026-10-27-results.json`:** ผลดิบทุกคำตอบ

## วิธีรัน

- เปิด container Ollama ชั่วคราว (`llm-bench-ollama`) ด้วยค่าเดียวกับ `docker-compose.yml` และ volume โมเดลเดิม
- ลบ container หลังทดสอบเสร็จ แต่ไม่ได้ลบ volume
