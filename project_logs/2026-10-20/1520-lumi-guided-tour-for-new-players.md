# บทแนะนำผู้ใช้ใหม่: Lumi พาเที่ยวแบบสปอตไลต์

**วันที่:** 2026-10-20 15:20 (Asia/Bangkok) — Person 3

## เหตุผล

ผู้ใช้ใหม่ไม่รู้ว่าเมนูและไอคอนบนแถบด้านบนใช้ทำอะไร ระบบเดิมคือ `WebTutorialModal` ซึ่งมีข้อจำกัด:
- เป็นแค่กล่องกลางจอ ไม่ชี้จุดจริง
- ไม่เปิดเอง
- ไม่จำว่าดูแล้ว

ผู้ใช้จึงขอระบบแนะนำแบบเกม ที่มีสปอตไลต์และตัวละครพาเที่ยว และให้ทำก่อนงาน Gemini ตรวจโค้ด Arcade ที่วางแผนไว้แล้ว

ผู้ใช้กำหนดเงื่อนไขของโหมดแข่งขันไว้ดังนี้:
- **LV. 1 (ยังล็อก):** พูดถึงสั้นๆ ว่าปลดล็อกที่ LV. 10
- **LV. 10 ขึ้นไป:** บอกให้กดเข้าไปดู แล้วแนะนำละเอียดตอนเข้าโหมดครั้งแรก

## ปัญหาที่เจอระหว่างทำ

- **แก้ `db.js` แล้ว server ไม่ยอมบูต** จึงล็อกอินไม่ได้
  - สาเหตุ: checksum ของ migration `202610120001` คิดจาก source ของ `initializeCoreSchema` และ migration นี้ถูก apply บนฐานจริงไปแล้ว
  - แก้โดย revert `db.js` แล้วย้ายไปเป็น migration ใหม่
  - **ห้ามแก้ฟังก์ชันใน migration ที่ apply แล้ว**
- **บัญชีถูกบันทึกว่าดู 2 บทแล้วภายใน 90ms**
  - สาเหตุ: tour แถบเมนูอยู่ระดับ App จึงค้างอยู่ตอนเปลี่ยนหน้า และซ้อนกับ tour ของหน้า Competitive พอกด Esc ครั้งเดียวก็ปิดทั้งสองบท
  - แก้โดยให้เปิดได้ทีละบท และ tour แถบเมนู key ตาม route (ออกจากหน้ากลางทางจะไม่ถูกบันทึกว่าดูแล้ว)
