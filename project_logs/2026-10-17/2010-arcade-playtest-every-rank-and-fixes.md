## สิ่งที่ตรวจแล้วถูกต้อง

- **คะแนน**: ตรงสูตร test + quality + time × multiplier ทุกแมตช์ (เช่น 100+85+22 = 207, Score Booster 200 → 400)
  - float 32.0 กับ 32 นับว่าถูก
  - ตัดสินอันดับจากคะแนนสะสม คัดออก 0/2/1/1 ตามกติกา ห้อง 2 คนจบหลังรอบ 2
- **เหรียญ**: ตรงตาราง 50/35/25/15/10 ทุกครั้ง
  - ยอดรวม 11,329 → 12,109 ตรงกับรางวัลอันดับบวกความสำเร็จ 3 อัน (ชนะครั้งแรก 150, รอบไร้ที่ติ 300, ขาประจำสนาม 200)
  - ตกรอบแล้วออกไปหน้าอื่นก็ยังได้เหรียญ ส่วนสละสิทธิ์ผ่านปุ่ม back ไม่ได้เหรียญ ตรงกับคำเตือน
- **ประวัติการเล่น**: การ์ดสถิติ, รายการแมตช์ และ "ย้อนดูโค้ดของคุณ" ตรงกับฐานข้อมูล
  - แมตช์ที่สละสิทธิ์ไม่ขึ้นในประวัติ
- **การสุ่มโจทย์**:
  - ง่าย/ปานกลาง/ยาก สุ่มเฉพาะระดับนั้น รอบ 4 ตาม `finalePoolByDifficulty`
  - ดั้งเดิมสุ่มง่ายคละปานกลาง ไม่ซ้ำในแมตช์เดียว
- **บอท**:
  - ซื้อของตามบุคลิก ใช้ไอเทมเฉพาะรอบ 2–4
  - ยิงผู้นำคะแนน ใช้เกราะ/Score Booster ของตัวเองได้ (คะแนน ×2 จริง)
  - ความเก่งไล่ตามระดับ: ง่าย ~95/รอบ, ปานกลาง ~150, ยาก ~230
- **ไอเทมกับผู้เล่น**:
  - Ink Fog บังจนคลิก editor ไม่ได้ (โดนจริงตอนเล่น โค้ดที่พิมพ์ไม่เข้า)
  - Screen Shake, Mirror, Screen Dimmer, Caps Lock โดนแล้วขึ้นแจ้งเตือน
  - ร้านค้า: ซื้อ, สุ่มใหม่ (200 → 400), ขายคืนครึ่งราคา

## บั๊กที่แก้ในรอบนี้

1. **ข้อความบอกว่า "ไอเทมยังใช้ได้ตามปกติ" หลังส่งคำตอบ** แต่ปุ่มถูกปิด และ server ปฏิเสธ (`arcade/shop-api.js`, commit 7f95dbc)
   - แก้ข้อความให้ตรงกับกฎจริง ทั้ง `translations.js` และ `BattleRoyaleGameplayView.jsx`
   - ไม่เปลี่ยนกฎเกม
2. **ตัวอย่างใต้โจทย์หายและปุ่ม "ทดสอบโค้ด" ไม่ได้ทดสอบอะไร** ตั้งแต่ 3b3521a (ซ่อนเทสไว้ที่ server แล้วไม่ส่งเคสใดเลย)
   - `server/arcade/public-task.js` (ใหม่) ส่งเฉพาะ `exampleCasesShown` เคสแรกเป็น `example_cases` + จำนวนเคสที่ซ่อน
   - เฉลยและเคสที่เหลือยังอยู่ที่ server
   - client (`useRoundJudging.js`) ใช้ตัวอย่างนี้แสดงใต้โจทย์และรันในปุ่มทดสอบ ข้อความผลเปลี่ยนเป็น "ผ่าน x จาก y ตัวอย่าง"
3. **Backspace Lock ไม่มีผล** เพราะฟัง keydown บน textarea ซ่อนที่ไม่เคยได้ focus
   - ย้ายไปใช้ `editor.onKeyDown` ของ Monaco และลบ textarea นั้น
4. **Caps Lock Trap เปลี่ยนโค้ดทั้งไฟล์เป็นตัวใหญ่** (`def` → `DEF`) ทำให้ทั้งรอบพัง
   - `typing-debuffs.js` (ใหม่) เปลี่ยนเฉพาะข้อความที่พิมพ์ระหว่างโดน
   - Key Scrambler/Glitch ก็ทำที่ตำแหน่งที่พิมพ์ ไม่ใช่ท้ายไฟล์
5. **บอทยิงคนที่ส่งคำตอบแล้ว** (editor ล็อกอยู่ ไอเทมเสียเปล่า) → `bot-ticker.js` เลือกเฉพาะคนที่ยังเขียนอยู่
6. **บอทบุคลิกซ้ำ** (ห้องเดียวมี Bot_SyntaxPro 3 ตัว) → `bot-api.js` เลือกบุคลิกที่ยังไม่มีในห้องก่อน
7. ข้อความเล็กๆ
   - คำอธิบายระดับ "ดั้งเดิม" เขียนว่าใช้โจทย์ประจำ 3 ข้อ แต่จริงสุ่มง่าย+ปานกลาง
   - AI Helper อ้างถึง "Gemini"
   - ดูโค้ดบอทที่เขียนครบ 100% แล้วยังขึ้น "กำลังเขียนอยู่"
