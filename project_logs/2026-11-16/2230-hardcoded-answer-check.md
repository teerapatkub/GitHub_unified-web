    - ถ้าคำตอบเปลี่ยนเพียงเพราะค่าคงที่ตัวนั้นถูกพิมพ์ออกมาตรงๆ ก็ยังนับว่าไม่เปลี่ยน

  - **ถ้าไม่มี `solution_code` จะข้ามการตรวจนี้ทั้งหมด** ผลเหมือนเดิม
- **ส่งเฉลยไปให้ตัวตรวจในทุกทาง:**

  - **มินิเกม:** เพิ่ม `solution_code` ใน SELECT และรับเฉลยใน `gradeMiniGameSubmission(code, config, files, { solutionCode })`
- **Competitive** (`POST /api/competitive/challenges`):
