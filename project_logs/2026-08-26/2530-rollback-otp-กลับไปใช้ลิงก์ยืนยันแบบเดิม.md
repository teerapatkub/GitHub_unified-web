# Rollback ระบบ OTP กลับไปเป็นแบบก่อนหน้า

**วันที่:** 2026-08-26 เวลา 01:30 (ของวันถัดไป)
**ผู้ทำ:** Person 3
**ที่มา:** ผู้ใช้สั่งให้ rollback กลับไปก่อนที่จะมี OTP

---

## ทำอย่างไร

**ใช้ `git revert` ไม่ใช่ `git reset`** — สอง commit ของ OTP ยังอยู่ในประวัติครบถ้วน
เพียงแต่มี commit ใหม่ที่ย้อนผลของมัน ถ้าวันหน้าอยากได้ OTP กลับมา
สั่ง revert ตัวที่ย้อนอีกทีก็ได้ของเดิมทั้งหมดคืน ไม่ต้องเขียนใหม่

```
b2be6db  fix: say when the verification mail did not go out ...   ← ย้อน
2dfeb21  feat: registration verifies the email with a code ...    ← ย้อน
a0d1d68  docs: record the Supabase import ...                     ← จุดที่กลับไป
```

ตรวจแล้วว่า `server/server.js`, `server/db.js` และ `client/src/pages/FriendLogin.jsx`
**เหมือนกับตอน commit `a0d1d68` ทุกตัวอักษร** (`git diff a0d1d68` ของสามไฟล์นี้ว่างเปล่า)
และไม่มีคำว่า `verify-otp`, `issueOtp`, `hasPendingOtp`, `otpMailFailed` หลงเหลือในโค้ดเลย

## สิ่งที่เก็บไว้ ไม่ได้ย้อนไปด้วย

**บันทึกการทำงานสองไฟล์ของ OTP ยังอยู่** (`2450-...` และ `2510-...`)
เพราะเป็นบันทึกว่าเกิดอะไรขึ้นจริง และไฟล์ `2510` มีเรื่องที่ยัง**เป็นจริงอยู่และสำคัญ**:
Gmail ปฏิเสธรหัสผ่านใน `server/.env` (`535-5.7.8`) ต้องใช้ App Password 16 หลัก
— ปัญหานี้ไม่ได้หายไปกับการ rollback เพราะระบบลืมรหัสผ่านใช้ตัวส่งอีเมลตัวเดียวกัน

## สถานะหลัง rollback

| เรื่อง | สถานะ |
|---|---|
| สมัครสมาชิก | กลับไปส่ง**ลิงก์**ยืนยันอายุ 24 ชม. เหมือนเดิม |
| เข้าสู่ระบบ | ไม่มีการกันบัญชีที่ยังไม่ยืนยันอีกแล้ว |
| `users.email_verified` | กลับไปเป็นคอลัมน์ที่ไม่มีใครเขียน (สถานะเดิมก่อนหน้านี้) |
| บัญชี `pong` ที่เคยติดค้างอยู่ที่หน้ากรอกรหัส | **เข้าใช้งานได้ตามปกติแล้ว** ไม่มีอะไรขวาง |

## ของที่ค้างในฐานข้อมูล

- **คอลัมน์ `purpose` / `attempts` / `last_sent_at` ใน `email_verifications` ยังอยู่**
  เพราะ `git revert` ย้อนได้แค่โค้ด ไม่ได้ย้อนฐานข้อมูล — ไม่มีผลอะไร โค้ดที่กลับมา
  ไม่ได้อ้างถึงคอลัมน์เหล่านี้เลย และ `purpose` มีค่า default เป็น `'link'` อยู่แล้ว
  จึงไม่ต้องแก้อะไรตอน INSERT แบบเดิม
- **ลบแถวที่ `purpose = 'otp'` ทิ้งแล้ว 2 แถว** เป็นรหัสที่ออกระหว่างทดสอบและระหว่างที่ผู้ใช้ลองสมัคร
  ตอนนี้ไม่มีโค้ดไหนอ่านแล้ว จึงเป็นขยะเปล่าๆ · แถว `purpose = 'link'` เดิม 15 แถวไม่ได้แตะ

## ถ้าอยากได้กลับมาภายหลัง

`git revert <commit ที่ย้อน>` แล้วโค้ด OTP ทั้งหมดจะกลับมาเหมือนเดิม
สิ่งที่ต้องแก้ก่อนใช้จริงคือ **App Password ของ Gmail** เพียงอย่างเดียว
ตัวระบบ OTP เองผ่านการทดสอบครบทุกเส้นทางแล้วตามบันทึกไฟล์ `2450`
