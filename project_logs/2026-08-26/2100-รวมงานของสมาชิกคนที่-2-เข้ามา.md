## วิธีที่ใช้รวม

**merge ไม่ใช่แทนที่** ตามที่ผู้ใช้สั่ง — `git merge origin/full_project-1` แบบ 3 ทาง
โดยมี `820d378` (commit ล่าสุดที่ผม push) เป็นจุดร่วม งานของทั้งสองฝั่งจึงอยู่ครบ
ไม่มีใครทับใคร

มี conflict จริง 2 จุด ที่เหลือ git รวมให้เองได้

### conflict 1 — `client/src/pages/FriendLogin.jsx`

สมาชิกคนที่ 2 เพิ่ม helper ของตัวเองไว้ในไฟล์:

```js
const API_BASE_URL = (import.meta.env.VITE_API_BASE_URL || "http://localhost:3001")...
const apiUrl = (path) => `${API_BASE_URL}${path}`;
```

ซึ่งเป็นคำตอบที่ **สอง** ของคำถามเดียวกับที่ก้อน 4 เพิ่งรวมไว้ที่ `client/src/config/api.js`
และค่าเริ่มต้นของเขาคือ `http://localhost:3001` ตรงๆ ซึ่งคือ hardcode ที่ทำให้ deploy ไม่ได้

**ตัดสิน:** เก็บตัวกลางตัวเดียว ลบ helper ในไฟล์ทิ้ง แล้วเขียนการเรียกของเขาด้วยตัวกลางแทน
เหตุผลเดียวกับที่โปรเจคนี้เคยมีตัวตรวจคำตอบ 5 ตัวแล้วให้ผลไม่ตรงกัน

**ฟีเจอร์ของเขายังอยู่ครบ** — ดึง Google Client ID จาก `/api/config/google` แทนที่จะฝังใน
bundle ซึ่งดีกว่าเดิมจริง และของผม (`use_fedcm_for_prompt`) ก็ยังอยู่ ทั้งคู่ทำงานร่วมกันได้

### conflict 2 — `server/server.js` เงื่อนไขการแสดงโจทย์แข่ง

ทั้งคู่แก้ `WHERE` ก้อนเดียวกัน ของผมคือซ่อนโจทย์หมดอายุ ของเขาคือเพิ่มขอบเขต `special`
กับให้โจทย์ `is_test` แสดงตลอด

**ตัดสิน:** ใช้ของเขา (เป็น superset) และเก็บคำอธิบายของผมไว้พร้อมเขียนเพิ่มว่าสองข้อยกเว้น
