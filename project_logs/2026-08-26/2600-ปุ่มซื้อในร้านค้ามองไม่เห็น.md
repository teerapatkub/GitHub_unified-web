## เหตุผล

ผู้ใช้แจ้งพร้อมภาพหน้าจอว่าปุ่มซื้อในร้านค้าล่องหน มีสองสาเหตุที่ไม่เกี่ยวกันเลย

**หนึ่ง — คลาส CSS ที่ไม่เคยมีอยู่จริง** `.python-gradient` ถูกใช้ 14 จุดใน 6 หน้า
และ `.whisper-shadow` ถูกใช้ใน 8 ไฟล์ แต่ไม่มีไฟล์ CSS ไหนประกาศไว้เลย Tailwind ไม่เตือน
เมื่อเจอคลาสที่ไม่รู้จัก มันแค่ปล่อยผ่าน ปุ่มที่ใช้ `python-gradient text-white` จึงเป็น
ตัวอักษรขาวบนการ์ดสีขาว — อยู่ตรงนั้น กดได้ แต่มองไม่เห็น

**สอง — ปุ่มซื้อรายชิ้นถูกซ่อนจนกว่าจะ hover** และการ์ดสินค้าซ้อน `absolute inset-0`
สามชั้นทับกัน ทำให้ป้าย "มีแล้ว" ถูกปุ่ม "สวมใส่" บังไว้ตลอดโดยไม่มีทางแสดงได้เลย

## ผลกระทบต่อส่วนอื่น

**กว้างกว่าร้านค้ามาก และเป็นผลดี** — การประกาศ `.python-gradient` ทำให้ปุ่มที่มองไม่เห็น
มาตลอดกลับมาเห็นได้ทั้งระบบ: ปุ่มเข้าสู่ระบบใน `Login.jsx` ปุ่มบันทึกโปรไฟล์สามจุดใน
`ProfilePage.jsx` แถบหมวดหมู่ที่เลือกอยู่ในร้านค้า และไอคอนหัวข้อในหน้าความสำเร็จกับ
กระดานอันดับ ส่วน `.whisper-shadow` เป็นเรื่องเงาการ์ดล้วนๆ

**ไม่กระทบฐานข้อมูล ไม่กระทบ Bot AI ไม่กระทบตัวตรวจคำตอบ** — ไม่มีการแตะฝั่ง server เลย
ตรรกะการซื้อ การสวมใส่ และการเรียก API ใน `ShopPage.jsx` ไม่ได้เปลี่ยนแม้แต่บรรทัดเดียว

`ShopPage.jsx` และ `index.css` อยู่นอกขอบเขตของ Person 3 — บันทึกไว้ใน
`docs/handoff-to-person-1.md` แล้วตามกฎใน CLAUDE.md
