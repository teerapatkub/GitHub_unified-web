# ธีมจากร้านค้าไม่ถูกนำมาใช้ในโหมดเกม

**วันที่:** 2026-08-26 เวลา 23:59
**ผู้ทำ:** Person 3
**ที่มา:** ผู้ใช้แจ้งว่า "ของตกแต่งธีมไม่ถูกนำมาใช้ใน Competitive Arena และ Arcade"

---

## ต้นเหตุ — ธีมทาลงบนคลาสเดียว และสองหน้านี้ไม่ได้ใช้คลาสนั้น

ธีมจากร้านค้าไม่ได้ทำงานด้วยการเปลี่ยนสีทีละที่ แต่ทำงานด้วยกฎเดียวใน `index.css`

```css
html[data-theme^="shop-theme-"] .bg-pysim-surface { ... }
```

หน้าไหนที่รากของหน้าใช้ `bg-pysim-surface` จะได้ทั้งสีพื้นและภาพพื้นหลังของธีมทันที
แต่สามหน้าของโหมดเกมเขียนสีพื้นเป็น `bg-slate-50` / `bg-slate-50/50` ตายตัว
ธีมจึงไม่มีทางไปถึง — ซื้อธีม ใส่ธีม เห็นผลทุกหน้า **ยกเว้นตอนเข้าไปเล่นเกม**

## ที่แก้

| ไฟล์ | เดิม | ใหม่ |
|---|---|---|
| `client/src/pages/Arcade/ArcadeBattleRoyale.jsx` | ราก `bg-slate-50` · แถบบน `bg-white` · เนื้อหา `bg-slate-50/50` | ราก `bg-pysim-surface` · แถบบนเพิ่ม `pysim-theme-navbar` · เนื้อหาไม่มีสีพื้นของตัวเอง |
| `client/src/pages/CompetitiveArena.jsx` | ราก `bg-slate-50/50` · แถบบน `bg-white/90` | ราก `bg-pysim-surface` · แถบบนเพิ่ม `pysim-theme-navbar` |
| `client/src/pages/MainMenu.jsx` | ราก `bg-slate-50/50` | ราก `bg-pysim-surface` |

รวม `/menu` เข้ามาด้วยทั้งที่ผู้ใช้ไม่ได้ระบุ เพราะเป็นประตูเข้าของทั้งสองโหมด
ถ้าแก้แค่สองหน้า ธีมจะหายไปหนึ่งหน้าตรงกลางแล้วกลับมา ซึ่งดูเหมือนของเสียมากกว่าเดิม

**ทำไมเนื้อหาของ Arcade ต้องเอาสีพื้นออก** — `bg-slate-50/50` คือสีขาวทับ 50%
เต็มพื้นที่ ถ้าปล่อยไว้มันจะนั่งทับภาพธีมแล้วทำให้จาง เมื่อไม่มีธีม สีที่เห็นเท่าเดิมทุกประการ
เพราะมันเคยทับอยู่บนสีเดียวกันกับตัวเองอยู่แล้ว

**พื้นที่เขียนโค้ดไม่ถูกแตะ** — คอลัมน์ editor กับกล่องผลลัพธ์ยังเป็นพื้นทึบเหมือนเดิม
ธีมมาแค่ที่เปลือกของหน้า ไม่ได้มาอยู่ใต้ตัวโค้ดที่ต้องอ่านตอนแข่ง

## ผลกระทบกับส่วนอื่น

- **ไม่มีการเปลี่ยน logic ใดๆ** เปลี่ยนเฉพาะคลาสของสีพื้น 5 จุด
- ตอนไม่ได้ใส่ธีม สีพื้นเปลี่ยนจาก `#F8FAFC` เป็น `#F8F9FA` (ห่างกันหนึ่งขั้น มองไม่ออก)
  ตรวจแล้วด้วยการอ่าน computed style จริงในเบราว์เซอร์
- ธีมในตัวที่ไม่ใช่ของร้านค้าไม่ได้รับผลกระทบ เพราะไม่เคยทาสีที่คลาสนี้อยู่แล้ว
