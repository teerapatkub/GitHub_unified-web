**บริบท**: ผู้ใช้แจ้งว่า "UI ไม่มีความ consistency กับหน้าจอเลย" ในหน้า Arcade Battle Royale (`client/src/pages/ArcadeBattleRoyale.jsx`) ตรวจสอบโค้ดทั้งไฟล์ (2,331 บรรทัด) เทียบ Tailwind class ระหว่างแต่ละ phase (Lobby, Shop, Round, Result) พบว่าดีไซน์โทเค็น (สี rose/slate, radius rounded-3xl/2xl/xl, shadow-sm, font-black) สอดคล้องกันดีอยู่แล้วในทุก phase — ปัญหาจริงที่ตรวจพบเป็นบั๊ก **i18n ไม่ครบ ไม่ใช่ปัญหาดีไซน์**: หน้า Lobby (ทั้ง Public Room Browser และ Room Lobby) และ 3 Modal (Create Room, Room Settings, Password Prompt) เขียนข้อความ hardcode เป็นภาษาไทยตรงๆ ในโค้ดทั้งหมด ไม่ผ่านระบบ `t()` เหมือนหน้า Shop/Round/Result เลย ทำให้เมื่อผู้ใช้กดปุ่มสลับภาษา (🇬🇧 English) หน้าจอบางส่วนเปลี่ยนภาษา บางส่วนไม่เปลี่ยน — นี่คือ "ไม่มีความ consistency" ที่สังเกตเห็นได้ชัดที่สุด

พบจุดที่ไม่สอดคล้องกันเพิ่มเติมระหว่างตรวจ:
- สถานะผู้เล่น "มีชีวิตอยู่" แสดงเป็น `'LIVED'` (hardcode ภาษาอังกฤษ) ในขณะที่สถานะ "ตกรอบ" ข้างเคียงใช้ `t('eliminated')` ถูกต้อง
- หน่วยคะแนนสลับใช้ `pt` และ `pts` ปนกันคนละจุด (ใน panel ผู้เล่นระหว่างเกม vs. หน้าผลสรุป)
- ป้ายกำกับ "(You)" ในหน้า Result เป็นภาษาอังกฤษ hardcode ในขณะที่ "(คุณ)" ในรายชื่อผู้เล่นห้อง Lobby เป็นภาษาไทย hardcode — คำเดียวกัน คนละภาษา คนละจุด
- ปุ่ม "🚪 ออกจากห้อง (Leave Room)" / "🔄 อยู่ในห้องเดิมต่อ (Remain in Room)" ในหน้า Result ผสมภาษาไทย+อังกฤษในปุ่มเดียว
