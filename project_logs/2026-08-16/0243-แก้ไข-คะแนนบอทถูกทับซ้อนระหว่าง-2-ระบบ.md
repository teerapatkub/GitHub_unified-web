## สาเหตุ
พบว่ามีระบบให้คะแนนบอท 2 ระบบที่แยกจากกันและชนกัน:
1. `evaluateRound()` ใน `ArcadeBattleRoyale.jsx` (ระบบตรวจโค้ดจริงที่ทำไว้ก่อนหน้า) ให้คะแนนบอทตามสูตร `passCount*10,000,000 + readability*10,000 + timeBonus` เข้า `opponents[i].score` ในสเกลเดียวกับผู้เล่นจริง
2. `botManager.js` (ของเดิม) sync ค่า `botInstance.score` (ตัวแปรภายใน `BotAIEngine` ที่ใช้แค่สำหรับ heuristic เลือกเป้าหมายของบอทเอง สะสมจากคะแนน "พิมพ์โค้ดเสร็จ" หลักร้อย-พัน) **ทับกลับเข้า `opponents[i].score` ทุก tick** โดยไม่มีเงื่อนไขใดๆ

ผลคือคะแนนจริงจาก `evaluateRound()` จะถูกลบล้างกลับเป็นค่าเล็กๆ ทันทีที่มี tick ถัดไปหลังจบรอบ ทำให้การคัดออก/จัดอันดับไม่ยุติธรรม

พบบั๊กที่เกี่ยวข้องอีกจุดระหว่างตรวจโค้ด: `eliminateBottom()` มาร์ค `opponents[i].eliminated = true` ใน React state เท่านั้น ไม่เคยบอก `BotAIEngine` instance จริงเลย ในขณะที่ `botManager.js` sync `eliminated: botInstance.eliminated` กลับ (ซึ่งไม่เคยเป็น `true` เพราะไม่มีใครตั้งมัน) ทำให้บอทที่ "ตกรอบ" แล้วอาจถูกดันกลับมาสถานะไม่ตกรอบทุก tick และยังคงซื้อ/โจมตี/เก็บคะแนนต่อไปได้ทั้งที่ UI บอกว่าตกรอบแล้ว

## สิ่งที่แก้ไข

### `client/src/bot/botManager.js`
- ลบ `score: botInstance.score` ออกจาก sync block — ให้ `evaluateRound()` เป็นเจ้าของคะแนนแต่เพียงผู้เดียว sync เหลือแค่ `cash`, `eliminated`, `isDebuffed`
- เพิ่มเมธอด `markEliminated(name)` ให้ `eliminateBottom()` เรียกได้ตรงๆ

### `client/src/pages/ArcadeBattleRoyale.jsx`
- `eliminateBottom()` เรียก `botManager.markEliminated(opponents[p.index].name)` เพิ่มเติมทุกครั้งที่คัดบอทออก ให้ `BotAIEngine` instance จริงรู้ตัวว่าตกรอบแล้ว (หยุดซื้อ/โจมตี/เก็บคะแนนจริง ผ่าน guard `if (this.eliminated) return;` ที่มีอยู่แล้วใน `botAI.js`)
