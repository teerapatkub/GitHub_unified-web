   - น่าจะมาจากงานที่ยังไม่ได้ commit ของสมาชิก
   - ไม่ได้แก้ฐานทดสอบ เปลี่ยนไปใช้ฐานในเครื่องแทน
3. **บั๊กเนื้อหาบทเรียน 1 สไลด์ 10:** กล่องโค้ดมีคำอธิบายภาษาไทยปนกับโค้ด กด Run Code แล้วขึ้น `SyntaxError`
   - ตอนแคปพิมพ์โค้ดตัวอย่างลงกล่องแทน
