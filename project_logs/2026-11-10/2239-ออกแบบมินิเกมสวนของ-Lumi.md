# ออกแบบมินิเกม "สวนของ Lumi" (ยังไม่มีโค้ด)

- **วันที่**: 2026-11-10
- **สิ่งที่เพิ่ม**: `docs/superpowers/specs/2026-11-10-lumi-garden-design.md` เป็น spec ของมินิเกมแนวเขียน Python สั่งหุ่นทำสวนบนกริด มีด่านหลัก 9 ด่าน โมดูลละ 1 ด่าน และมีฟาร์มอิสระ
- **เหตุผล**: ผู้ใช้อยากได้มินิเกมช่วยการเรียนรู้แนวเขียนโปรแกรมให้หุ่นทำงานอัตโนมัติ ออกแบบเป็นของ PySim เอง ไม่ลอกเกมใด
- **การตัดสินใจหลัก**
  - กฎทั้งหมดอยู่ใน engine Python ไฟล์เดียว ใช้ทั้งใน Pyodide และฝั่ง server
  - server รันซ้ำเองก่อนจ่าย XP/ทอง
  - ฟาร์มอิสระให้ทองได้ไม่เกิน 50 ทองต่อวัน และขายได้ครั้งละไม่ต่ำกว่า 10 นาที
- **ผลกระทบ**
  - จะมีตารางใหม่ `garden_progress` และ `garden_free_state`
  - แตะระบบเรียนและ gamification ซึ่งเป็นขอบเขตของ Person 1 ต้องลงบันทึกใน `docs/handoff-to-person-1.md` ตอนลงมือ
  - ไม่แตะตาราง `arcade_*` หรือบอท
- **ยังไม่เสร็จ**
  - รอผู้ใช้ตรวจ spec
  - ยังไม่ได้ทำ implementation plan
  - ยังไม่มีโค้ด
