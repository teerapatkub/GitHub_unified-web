## สิ่งที่แก้

### 17: token สีชุดเดียว (expand)
- **`client/src/styles/tokens.css`:** ตัวแปร `--c-*` เป็นแหล่งสีที่เดียวของเว็บ
  - เก็บเป็น RGB channel (`20 93 145`) เพื่อให้ `/opacity` ของ Tailwind ใช้ได้
  - มีกลุ่ม brand, surface/text, `label`, `accent` (สีประจำโหมด), สถานะ 4 กลุ่ม, `inverse-*` (คอนโซลมืด) และขนาด (`--text-label-min` 12px, `--target-min` 32px, `--target-primary` 44px)
- **`tailwind.config.js`:** `pysim-*` และชื่อเดิมอีก 3 ชุด (`t-*`, `cyber/neon/cat`, `bg-primary` ฯลฯ) อ่านจาก `--c-*` ทั้งหมด
- **`index.css`:** `--color-*` เป็น alias, ลบบล็อก sakura/ocean ที่ไม่เคยถูกใช้
- **ธีมร้านค้า (`themes/shopPalette.js`):** เขียน `--c-*` ด้วย
  - มี `readable()` ที่ทำให้สีตัวอักษรเข้มขึ้นจนผ่าน 4.5:1 เพราะสี accent ของธีมมักไม่ถึง (ซากุระ 3.5:1)
  - สีสถานะไม่เปลี่ยนตามธีม
- **`ThemeContext.jsx`:** ตอนเปลี่ยนธีม ลบตัวแปรของธีมก่อนหน้า ไม่อย่างนั้นถอดธีมแล้วสีค้าง
- **ร้านค้า:** ปุ่ม "ซื้อ" และ "กำลังสวมใส่" ใช้ token

### 18: Arcade บน token
- สีดิบ 630 จุดใน 19 ไฟล์ แปลงด้วยสคริปต์ (ตอนนี้อยู่ที่ `client/scripts/migrate-raw-colors.py`) แล้วแก้พื้นมืดด้วยมือให้ใช้ `inverse-*`
- ตัวอักษร 8–11px 51 จุด เปลี่ยนเป็น `text-label`
- ปุ่มเล็ก (ปุ่ม emoji ในแชท, ปุ่มเตะ/โอนหัวห้อง, ปุ่มย่อ/ขยาย, ปุ่มรีเฟรช, ปุ่มจำนวนคนในตั้งค่าห้อง) ได้ `min-h-target`
- **contrast:**
  - ไอคอนหัวห้องและแถบเตือนที่เป็นตัวขาวบนเหลือง (2.1:1) เปลี่ยนตัวอักษรเป็นสีเข้ม
  - overlay "ส่งคำตอบรอบนี้แล้ว" เดิมพื้นมืด 60% ทำให้ตัวอักษรเหลือ 3.2:1 เปลี่ยนเป็น 80% ได้ 6.4:1
  - ชื่อของ Ink Fog ใหญ่ขึ้นเป็น 20px ให้นับเป็นตัวอักษรใหญ่ (5.2:1)
  - ตัวหนังสือเตือนบน blackout เดิมเป็น red-500 บนดำ เปลี่ยนเป็น `inverse-accent`
- hover ที่ซ้ำกับสีพื้น (เดิม rose-600 → hover rose-500 กลายเป็นสีเดียวกันหลังแปลง) เปลี่ยนเป็น `/90` 11 จุด
- **`client/scripts/audit-page.js`:** ย้ายสคริปต์ audit มาไว้ใน repo
  - เกณฑ์ตัวอักษรเล็กเป็น < 12px
  - มี `window.AUDIT_SCOPE`
  - ผสมสีพื้นโปร่งแสงก่อนคำนวณ contrast (เดิมนับพื้นโปร่งเป็นขาว จึงวัด overlay ผิด)

### 19: แถบด้านบนบนมือถือ
- **< 640px:** แถวเดียว มีโลโก้ (ซ่อนชื่อแบบยังให้โปรแกรมอ่านหน้าจออ่านได้), โปรไฟล์, เหรียญ, ปุ่มของหน้า และปุ่ม ⋯
  - ภาษา ร้านค้า ตารางอันดับ และวิธีใช้ อยู่ในเมนู ⋯
  - DOM ชุดเดียว บนจอกว้าง wrapper เป็น `display: contents` ปุ่มจึงอยู่ที่เดิม
- **เมนู ⋯:** ปุ่มมี `aria-expanded`/`aria-controls`, Escape ปิดแล้วคืน focus, คลิกนอกเมนูก็ปิด
- **ข้อความ "ปลดล็อกที่เลเวล 10":** ซ่อนบนมือถือ แต่ยังถูกอ่านผ่าน `aria-describedby` ของแท็บที่ล็อก
- **สีของแถบ:** ใช้ token แถบจึงเปลี่ยนตามธีมด้วย
- **ทัวร์ Lumi:** เพิ่มขั้น "เมนูเพิ่มเติม" ที่ขึ้นเฉพาะบนมือถือ เพราะขั้นของปุ่มที่ถูกพับจะถูกข้าม
- **ป้ายโหมดผู้ชมใน Arcade:** ซ่อนบนมือถือ ไม่มีที่ในแถวเดียว
