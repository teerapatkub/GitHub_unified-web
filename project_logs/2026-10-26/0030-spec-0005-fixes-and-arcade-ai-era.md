**วันที่:** 2026-10-26 00:30 (Asia/Bangkok) — Person 3

## สิ่งที่เพิ่ม
- `specs/0005-arcade-and-student-ui-fixes.md` (ใหม่) สถานะ `ready-for-agent`
  - รวมบั๊ก A1–A11, U1–U11 จาก user test และข้อ 1–16 จาก UI audit
  - เรียงเป็นระยะ 0 (ต้องแก้ก่อน: A1, A2, U4) → ระยะ 1 (Track A–F ทำพร้อมกันได้) → ระยะ 2 (Track H: token/ขนาด) → ระยะ 3 (Track G)
  - Track C: ประวัติแมตช์ย้ายลงใต้รายการห้อง เหลือ 3 แมตช์ล่าสุดในล็อบบี้ และมีหน้าประวัติเต็มที่แบ่งหน้าใน SQL
  - Track G: ตอบคำถามของอาจารย์ด้วย "รูปแบบรอบ" ใหม่ (แก้โค้ดที่ AI เขียน, ทายผลลัพธ์, ตรวจคำตอบ AI) และผู้ชมที่มีส่วนร่วม โดยใช้คำตอบผิดที่ bot-coder สร้างและตรวจไว้แล้วเป็นวัตถุดิบ

## เหตุผล
- ผู้ใช้ขอให้รวมผลสองรอบเป็น spec เดียวพร้อมลำดับ และเพิ่มสองเรื่อง
- เลือกหน้าแยกแทน popup สำหรับประวัติ เพราะประวัติยาวไม่จำกัด ปุ่มย้อนกลับใช้ได้ และไม่ต้องดูแล focus ของ popup อีกตัว
- Track G ไม่ไล่จับคนใช้ AI แต่เปลี่ยนสิ่งที่วัด และไม่เอาโมเดลเข้าเส้นทางให้คะแนน (ADR 0007)

## ผลกระทบ
- ยังไม่ได้แก้โค้ดหรือ schema
- Track G ถ้าทำจะเพิ่มค่าเฉพาะโหมดใน `problem_modes` และค่าใหม่ในห้อง Arcade (ห้องเก่าอ่านเป็น `write`) ต้องรัน `test:problems`, `test:arcade`, `sim:bots`
