## สิ่งที่แก้

### 04: popup ตัวกลาง (audit P1 ข้อ 3, บั๊ก A6)
- เพิ่ม `client/src/components/ui/Dialog.jsx` และ `dialogFocus.js` (logic ของ Tab ที่ทดสอบได้)
  - ใช้ทัวร์ Lumi เป็นแบบ: `role="dialog"`, `aria-modal`, ชื่อจากหัวข้อ, focus trap, Escape ปิด, คืน focus ให้ปุ่มที่เปิด
- popup ของ Arcade ทั้ง 5 ตัวย้ายมาใช้ Dialog: สร้างห้อง, ตั้งค่าห้อง, คู่มือไอเทม, รหัสผ่านห้อง, ยืนยันออกระหว่างแข่ง
  - ปุ่มเลือกเป็น group ที่มี `aria-pressed`
  - label ผูกกับช่องด้วย `htmlFor`
  - ปุ่ม × มี `aria-label`
  - ช่องรหัสผ่านห้องกด Enter ส่งได้
  - ยืนยันออกระหว่างแข่ง: focus เริ่มที่ "อยู่ต่อ"

### 05: debuff กับ reduced motion (audit P1 ข้อ 4, P3 ข้อ 16, บั๊ก A5)
- Earthquake เดิมใช้ `animate-bounce`
  - เปลี่ยนเป็นคลาส `arcade-shake` ใน `arcade-effects.css`
  - เมื่อเปิด `prefers-reduced-motion` จะเปลี่ยนเป็นเบลอแบบไม่ขยับ ระยะเวลาเท่าเดิม
- toast เปลี่ยนจาก class ที่ไม่มีอยู่จริง (`animate-bounce-slight`) เป็นการเลื่อนเข้าแบบนุ่ม
- pulse และไอคอนหมุนใน Arcade ใช้ `motion-safe:`
- ข้อความบนจอของ Ink Fog และ EMP เป็นไทย/อังกฤษตามภาษา และดึงจำนวนวินาทีจาก `arcadeConfig.effectDurations`

### 06: ป้ายผู้สังเกตการณ์และปุ่มออก (บั๊ก A3, A4)
- `spectatorView.js` กำหนดว่าเป็นผู้สังเกตการณ์ได้เฉพาะ ROUND/SUMMARY/SHOP เท่านั้น
  - เพราะ `is_eliminated` ค้างเป็น 1 หลังจบแมตช์
- ออกจากห้องหรือเลือก LEAVE แล้วล้างสถานะของแมตช์นั้นทิ้ง
- หน้าตกรอบมีปุ่ม "ออกจากห้อง" พร้อมคำเตือน
  - ถ้าออกจะไม่ได้ทองตอนจบ และแมตช์จะไม่ขึ้นในประวัติ เพราะแมตช์ไม่เคยได้ `match_ended_at`

### 07: สร้างห้อง/รีเฟรช (บั๊ก A8, A9, A11)
- **สร้างห้อง:**
  - `POST /api/arcade/rooms/create` ย้ายจาก `server.js` ไป `arcade/lobby-api.js` และส่งรายชื่อผู้เข้าร่วม (มีหัวห้องแล้ว) กลับไปด้วย
  - `generateRoomCode` ย้ายตามไปด้วย
  - helper ของเทสคืน `room_id` จาก `INSERT … RETURNING` ได้แล้ว
- **รีเฟรชระหว่างแข่ง:** ขึ้น "กำลังกลับเข้าแมตช์ของคุณ…" แทนรายการห้อง (`hasSavedActiveRoom`)
- **ฟอร์มสร้างห้อง:** ใช้ค่าเริ่มต้นชุดเดียว (`newRoomForm`) และผู้เล่นสูงสุดเริ่มที่ 5 ตามค่าเริ่มต้นของ server (เดิม 4)
- **poll รายการห้อง:** หยุดเมื่ออยู่ในห้องแล้ว

### 08: ทองจากความสำเร็จบนหน้าสรุป (บั๊ก A10)
- ความสำเร็จถูกตรวจใน ticker หลัง settle ไม่ได้อยู่ในคำตอบ HTTP ใด จึงเก็บผลไว้ที่ `arcade_reward_receipts.achievement_rewards`
  - เป็น migration ใหม่ 202610260001 (`arcade/migrate-achievement-rewards.js`)
  - เก็บผลของการตรวจครั้งแรกเท่านั้น
- poll ของห้องส่ง `viewer_reward` ({coins, achievements}) ของผู้ที่ดูอยู่คนเดียว
- หน้าสรุปแสดงยอดรวม แล้วแยกบรรทัด "จากอันดับที่จบ" กับ "ความสำเร็จ: …"
- **ข้อผิดพลาดระหว่างทำ:** ตอนแรกแก้ `migrate-rewards.js` ซึ่งเป็นส่วนหนึ่งของ migration ที่รันไปแล้ว ทำให้ server บูตไม่ขึ้นเพราะ checksum ไม่ตรง ("Applied migration 202610120001 differs") จึงย้อนการแก้ไขแล้วทำเป็น migration ใหม่แทน
