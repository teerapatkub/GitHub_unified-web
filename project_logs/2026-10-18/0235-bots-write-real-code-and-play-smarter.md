# บอท Arcade เขียนโค้ดจริงและเล่นฉลาดขึ้น

**วันที่:** 2026-10-18 02:35 (Asia/Bangkok) — Person 3 (Arcade)
**ADR:** `docs/adr/0005-arcade-bots-write-real-answers.md`

## เหตุผล

ผู้ใช้ต้องการให้บอท "มีชีวิต" คือแข่งเขียนโค้ดจริงและเล่นฉลาดขึ้น

ปัญหาก่อนหน้านี้:
- บอทมีแค่หลอดความคืบหน้า และคะแนนเป็นค่าสุ่ม
- ไอเทมส่วนใหญ่ไม่มีผลกับบอท
- บอทซื้อของแบบสุ่ม ซื้อ AI Helper ที่ไม่มีประโยชน์กับตัวเองด้วย
- บอทยิงแต่ผู้นำ และไม่พูดอะไรเลย

ผู้ใช้เลือกวิธี "พิมพ์จากเฉลยและใส่ข้อผิดพลาดจริง" แทนให้ AI เขียน และให้ทำครบทั้งเรื่องเงิน การยิง และการตอบสนองแบบคน

## ผลกระทบ / ข้อควรรู้

- ไม่เปลี่ยน schema (ใช้ `draft_code`, `submitted_*` เดิม และ key ใหม่ใน JSONB `bot_state`)
- ตรวจคลังคำตอบราว 1.5 วินาทีต่อโจทย์ บอทจึงเริ่มพิมพ์ช้านิดหน่อยตอนต้นแมตช์หรือหลัง server restart
- cache อยู่ในหน่วยความจำ ถ้าแก้โจทย์ใน DB ต้อง restart
- ผู้เล่นที่ส่งแล้วหรือตกรอบดูโค้ดบอทได้ เฉลยจึงไม่หลุดถึงคนที่ยังเขียนอยู่
- บอทที่แข่งในโหมดเร็ว ความเร็วพิมพ์สเกลตามความยาวรอบ (`roundPaceScale` เดิม)
